# M24-04 release evidence

These JSON files are the frozen local evidence for the provisional M24-04
external transport evaluator. `evaluation.json`, `benchmark.json`, and
`coverage.json` are checked by `tools/verify_m2404_release.py`.
`package.json` is populated only after final wheel/sdist and isolated-import
verification. Generated coverage, build, and installation directories are
not committed.
