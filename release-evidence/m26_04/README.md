# M26-04 release bundle

This directory records the reproducible release evidence for the provisional
API/SDK/CLI gateway. Evaluation, benchmark, coverage, and package hashes were
generated from the clean `module/M26-04-api-sdk-cli-gateway-provisional`
worktree. The generated build and isolated-install directories were removed
after verification.

The package is not a clinical or production authorization system. It exposes a
typed caller-declared surface, preserves evidence and provenance, and abstains
when any required control or compatibility condition is unresolved.
