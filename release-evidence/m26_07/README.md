# M26-07 release bundle

This directory records reproducible release evidence for the provisional
change-control and tested-rollback module. Evaluation, benchmark, coverage,
and package hashes were generated from the clean
`module/M26-07-change-control-rollback-provisional` worktree. Generated build
and isolated-install directories are removed after verification.

The package is not a production deployment or authorization system. It
preserves caller-declared evidence and abstains when a required control,
revalidation, comparison, or rollback condition is unresolved.
