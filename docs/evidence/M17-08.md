# M17-08 evidence inventory

This G5 package verifies bounded translation-health monitoring, rollback decisions and safe
failure over synthetic, non-clinical declarations. It does not authenticate upstream content,
identity, consent, measurements, model output, biological truth, or treatment decisions.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Authority-bound contract | `src/glio_proteogen/contracts/m17_08/` | exact dossier SHA/slice, strict provisional schemas, parent and safety ceiling |
| Locked scenario corpus | `tests/fixtures/m17_08/scenarios.json` | eight scenarios, authority metadata, eight adversarial cases, ≥95% target |
| Runtime/adversarial tests | `tests/runtime/test_m17_08_monitoring.py` | healthy/degraded/rollback/suspension/abstention, controls, media and replay |
| Interface tests | `tests/integration/test_m17_08_interfaces.py` | schema GET, API POST, CLI monitor/schema parity, plugin descriptor |
| Executable evaluator | `evals/m17_08/run.py` | declared-oracle execution and 8/8 (100%) adversarial coverage |
| Microbenchmark | `evals/m17_08/benchmark.py` | one warm-up plus 25 public monitor calls and mean/p95 budgets |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M17-08.csv` | dossier requirements mapped to implementation and evidence |
| Data/model manifest | `docs/modules/GLIO-PROTEOGEN-M17-08.manifest.md` | synthetic metadata, zero executed models, no external traversal |
| Review / rollback | governed external process | reviewer authentication, exceptions and append-only recovery remain external |

Result provenance binds the rollback artifact and every telemetry, support-drift,
workflow-effect, discrepancy, and rollback-policy evidence digest, preserving the
complete nested monitoring input lineage for replay and audit.
