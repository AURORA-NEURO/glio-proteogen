# M24-04 external transport evaluator release evidence

M24-04 is a provisional, caller-declared external transport evaluator beneath
the biomarker-panel boundary. Its only scientific inputs are four explicitly
retained artifacts: a mass-spectrometry proteome, a genome/transcriptome
bundle, PTM annotations, and a benchmark package. The evaluator assesses the
seven declared transport dimensions (site, lab, platform, treatment era,
population, disease class, and specimen) using independent validation records
and calibration-floor decisions.

The runtime fails closed on any missing or denied authorization control. It
abstains when a dimension is not evaluable or calibration narrows the support
domain, and never converts missing transport evidence into a negative
biological claim. The result carries seven typed uncertainty dimensions,
provenance, limitations, evidence references, human-review semantics, and
canonical request/result digests for replay and tamper detection.

The ABI remains explicitly provisional (`0.1.0-provisional`, G3, S3). The
module does not emit a biomarker-panel conclusion, kinase state, generic
all-omics fusion, treatment recommendation, identity inference, consent
inference, or raw scientific-content traversal. Generated coverage, build,
installation, and temporary benchmark directories are excluded from the
committed source tree.
