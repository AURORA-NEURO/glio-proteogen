# M18-08 evidence inventory

This G5 package verifies bounded translation-health monitoring, support drift, workflow effects,
discrepancies, suspension and rollback over synthetic, non-clinical declarations. It does not
authenticate upstream content, identity, consent, measurements, biological truth, treatment
decisions, kinase activity, or generic all-omics fusion.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Authority-bound contract | `src/glio_proteogen/contracts/m18_08/` | exact dossier SHA/slice, strict provisional schemas, parent and safety ceiling |
| Locked scenario corpus | `tests/fixtures/m18_08/scenarios.json` | eight scenarios, authority metadata, eight adversarial cases, >=95% target |
| Runtime/adversarial tests | `tests/runtime/test_m18_08_monitoring.py`, `test_m18_08_adversarial.py` | health states, unsupported and non-evaluable abstention, controls, media and replay |
| Interface tests | `tests/integration/test_m18_08_interfaces.py` | schema GET, API POST, CLI monitor/schema parity, sealed plugin token |
| Executable evaluator | `evals/m18_08/run.py` | declared-oracle execution and 8/8 (100%) adversarial coverage |
| Microbenchmark | `evals/m18_08/benchmark.py` | one warm-up plus 25 deterministic public monitor calls and budgets |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M18-08.csv` | dossier requirements mapped to implementation and evidence |
| Data/model manifest | `docs/modules/GLIO-PROTEOGEN-M18-08.manifest.md` | synthetic metadata, zero executed models, no external traversal |
| Release evidence | `release-evidence/m18_08/` | evaluator, benchmark, branch coverage, package hashes and isolated import |
| Review / rollback | governed external process | reviewer authentication, exceptions and append-only recovery remain external |

Focused commands:

```text
uv run pytest --no-cov tests/contract/test_m18_08_provisional.py tests/runtime/test_m18_08_monitoring.py tests/runtime/test_m18_08_adversarial.py tests/integration/test_m18_08_interfaces.py tests/evaluation/test_m18_08_evidence.py
uv run python -m evals.m18_08.run
uv run python -m evals.m18_08.benchmark
```

The scoped branch-enabled coverage gate includes contract, runtime/plugin/service and evaluator
sources. Generated coverage XML, build directories and isolated install targets are evidence-only
and are removed before commit.
