# M15-03 evidence inventory

This package verifies deterministic mechanistic feature construction over synthetic,
caller-declared references. It covers units, topology/perturbation gates, parent binding,
support/uncertainty/provenance, safe abstention, strict interfaces, replay/tamper, and package
reproducibility. It does not authenticate external evidence, execute a biological model, infer
identity or consent, own kinase activity, fuse all omics, or recommend treatment.

## Safety controls

- Seven controls are inspected before typed traversal; arbitrary mappings and hostile attribute
  access fail closed.
- The M15-02 input is retained as an opaque artifact and bound by exact media type. The runtime
  never dereferences its content or treats a digest as issuer authentication.
- Units, finite numeric values, parent binding, topology and perturbation gates are explicit;
  unresolved/conflicted/abstained features produce safe abstention.
- Every output carries typed seven-dimension uncertainty, control provenance, limitations, and
  an evidence-role envelope. Abstention requires human review acknowledgement.
- Canonical request/result digests, derived IDs, and replay verification reject tampered output.

The release verifier is standard-library only and checks the frozen fixture digest, exact
evaluator case closure, benchmark thresholds, branch coverage threshold, traceability, and
wheel/sdist hashes plus isolated import evidence.
