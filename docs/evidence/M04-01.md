proteoform/isoform protocol and metadata profile. It checks declarations, relational closure,
strict construction, authorization ordering, canonical digests, immutable recovery, and the
closed `protein_rna_discordance` handoff. It does not inspect measurements, execute PCA/ICA or
multi-block PLS, infer a proteoform, isoform, PTM, abundance, or discordance, establish reference

## Locked risk controls

- All seven caller controls—approved configuration, identity/lineage, provenance, consent,
  quality, support, and intended use—are checked before protocol/profile/reference traversal.
  Every individually denied control and a hostile `dict` subclass must yield authorization
  rejection with zero governed traversals.
- Request and context identity, module/operation/version, profile/schema pin, and all derived
  digests close exactly. Split identifiers, stale pins, duplicates, contradictions, and re-signed
  forgery are rejected rather than silently repaired.
- The protocol contains exactly 11 sections. All seven identity keys, ten unresolved states,
  eight handoff roles, 21 output evidence entries at maximum, and three exact limitations are
  closed collections with duplicate and first-excess rejection.
- The reference bundle binds exact canonical protein, isoform, genome, transcript, PTM annotation,
  and coordinate declarations. Coordinate policy uses separate genome, transcript, and protein
  conventions, an exact `coordinate_mapping_version`, and explicit validation/conversion
  booleans; reference cardinality closes separately. Missing isoform reference, non-closing
  reference cardinality, and artifact identity conflict are structural failures. A coordinate-
  profile mismatch quarantines with a typed finding.
- Bottom-up uniqueness is relative to the exact reference bundle. Top-down evidence requires an
  intact-proteoform declaration; splice-junction policy requires transcript support; sequence-
  variant policy requires genome support; shared evidence cannot become a member-specific claim;
  and insufficient independent discriminators quarantine. These are policy checks only, not
  evidence classification or molecular inference.
- PTM policy preserves ambiguous site sets and distinguishes unlocalized from absent. It requires
  residue validation and reviewed threshold, unit, and labile-modification handling. M04-01 does
  not localize a PTM or authenticate the annotation reference.
- Quantification policy admits only reviewed method/normalization pairs, prohibits zero without an
  observation policy, and keeps missing, not-detected, and below-LOD states distinct. No accepted
  declaration establishes abundance accuracy or protein-RNA discordance.
- The exact eight-role handoff contains metadata receipts only and preserves
  `protein_rna_discordance` as context, never as an inferred result. Every authority flag remains
  literal and false for proteoform/isoform/PTM/abundance/discordance/proteotype/subtype/kinase,
  generic fusion, treatment, and clinical claims.
- Canonicalization applies only to semantically unordered values. Reordering yields complete
  request/result/receipt equality and stable digests; it cannot conceal a duplicate.
- Strict ingress rejects duplicate JSON keys, scalar coercion, unknown fields or terms, non-finite
  values, missing mandatory members, invalid media types, oversize canonical requests, stale
  derived values, and relational contradiction.
- Recursive privacy tests require opaque content-derived identifiers, enforce the artifact
  media-type allowlist, and prove that a biological canary is never reflected through results,
  findings, evidence, provenance, receipts, or limitations.
- Recovery is append-only. A corrected request explicitly supersedes the immutable prior result;
  it never mutates, deletes, re-signs, relabels, or silently promotes earlier evidence.

## Contract and interface plan

The public schema registry exports exactly these 13 JSON Schema 2020-12 names:
`request`, `output`, `protocol`, `profile`, `reference-bundle`, `reference-cardinality`,
`coordinate-policy`, `evidence-eligibility-policy`, `isoform-discrimination-policy`,
`modification-localization-policy`, `quantification-policy`, `discordance-handoff`, and `receipt`.
Unknown schema names fail closed.

The Python boundary is `evaluate_proteoform_protocol`. HTTP exposes
`POST /v1/modules/M04-01/protocol-conformance` and
`GET /v1/contracts/M04-01/{name}/schema`. CLI exposes
`proteoform-protocol validate REQUEST` and `proteoform-protocol export-schema NAME`. Successes,
typed quarantine results, strict reconstruction failures, authorization failures, canonical JSON,
and digests must be equivalent across all applicable interfaces. No interface may bypass raw
authorization preflight or accept a looser request than the public Python contract.

## Benchmark criterion

The benchmark builder creates one exact maximum conformant profile and all external declarations
before measurement. One untimed public call verifies conformity, maximum cardinalities, exactly
21 evidence entries, exactly three limitations, exact parent context, false authority flags, and
determinism. It then measures exactly 25 calls to public `evaluate_proteoform_protocol`; setup,
fixture loading, serialization, imports, CLI startup, HTTP transport, and reporting remain outside
the timed boundary. The nearest-rank p95 sample is used. Passing requires both mean <=2,000,000,000
ns and p95 <=3,000,000,000 ns.

This is a latency regression threshold only. It provides no evidence for molecular-identification
accuracy, uncertainty coverage, calibration, supported perturbations, distribution shift,
biological validity, subgroup performance, transportability, human factors, or prospective use.

## Manifest, review, and rollback evidence

The [module manifest](../modules/M04-01.manifest.md) records the synthetic data boundary, every
caller-declared reference role, and the dossier's PCA/ICA and multi-block PLS entries as
`declared_not_executed`. The installed model count is zero. M04-01 performs no training,
inference, scoring, or calibration and does not fetch or parse a reference artifact.

Human review is external and cannot be self-issued. A valid G0 sign-off record binds reviewer
identity and role, decision, timestamp, version, schema digests, fixture digest, executable report,
benchmark report, and exact release artifact. Critical discrepancy, novel/OOD state, support
override, claim promotion, release exception, and unresolved biological conflict remain
quarantined until that governed process acts.

Rollback preserves the failed request/result and restores the last approved deployment through
the governed release mechanism. Recovery corrects the authoritative source, creates a new
superseding request/result, replays the complete evidence package, and obtains new sign-off. It
does not rewrite history or treat a later conformant result as proof that the earlier result was
conformant.

## Exact limitations and claims ceiling

The result carries exactly these three fixed limitations, in canonical order: code
`proteoform_protocol_conformance_only` states that only declared protocol metadata is validated
and no signal is inspected or scientific inference performed; code
`external_reference_authority_unverified` states that reference, configuration, control, and
review authorities remain caller-declared and unauthenticated by M04-01; and code
`protein_rna_discordance_not_inferred` states that the handoff preserves metadata and unresolved
states without a protein-RNA-discordance, proteotype, subtype, kinase, or treatment claim. No
caller-supplied limitation may broaden or replace them.

The dossier's later G1, G3, and G4 criteria remain future governed gates. This G0 package locks
machine-validatable mandatory fields, units, identity keys, version rules, strict schemas,
interface parity, safe failure, provenance, and rollback evidence. It does not claim primary-error
tolerance, perturbation robustness, nominal 90% uncertainty coverage, clinical-grade recovery, or
scientific validation.

## Current-base hostile-input hardening

The public evaluator now applies a bounded plain-value traversal before strict
Pydantic reconstruction: 72 container levels, 512 mapping members, 4,096
sequence members, and 150,000 visited nodes. These limits are an ingress
resource-safety boundary and do not change any frozen M04-01 field, schema,
cardinality, result, or digest semantics. A deeply nested authorized mapping
is rejected as a typed strict-input failure instead of leaking a raw
`RecursionError`; the regression is covered in
`tests/contract/test_m04_01_boundaries.py`.
