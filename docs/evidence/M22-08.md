# GLIO-PROTEOGEN M22-08 evidence

M22-08 is a provisional evidence gate and release adjudicator beneath
Orthogonal immunoassay validation. It evaluates caller-declared traceability,
quality, support, claim-ceiling, risk, approval, and post-release obligations
for the parent target `protein-RNA discordance`. It emits only an adjudication
record and, when the gate is closed, a signed release record; it never emits a
protein-RNA estimate, treatment recommendation, identity inference, kinase
activity, or generic all-omics result.

Authority is the permitted dossier SHA-256
`sha256:0a6b200cbe073db13a4bcf315edc23ab97edfe6f500bc7ea2785f5e1c70da181`,
exact slice `GLIO-PROTEOGEN_240_Module_Dossier.md:7904-7944`. The ABI remains
`0.1.0-provisional`, owner Quality engineering, safety class S3, and release
gate G5. The implementation treats the M22-07 upstream as an opaque,
caller-declared artifact and binds its exact artifact identity without
inventing an upstream service import.

The deterministic engine requires seven-control authorization, complete
requirement categories, benchmark floors, residual-risk closure, signed
approval, post-release obligations, evidence, provenance, and seven typed
uncertainty dimensions. Failed requirements, failed benchmarks, open critical
risk, deferred approval, unsupported controls, source substitutions, and
non-evaluable input fail closed as block/review/abstain outcomes. Canonical
request/result digests and replay/tamper verification close the audit trail.
Replay regenerates the full adjudication from the validated request and compares
the canonical result, so self-rehashed release-record or evidence mutations are
rejected rather than accepted as authentic.

Evidence is recorded in `release-evidence/m22_08/` and verified by
`tools/verify_m2208_release.py`. The focused matrix now includes 40 tests,
including valid self-rehashed release-record/evidence mutations and an invalid
self-rehashed record that must fail closed before canonical comparison.

Provenance also binds benchmark report artifacts and every evidence digest
declared by requirements, benchmarks, residual risks, approvals, post-release
obligations, and the locked gate configuration. These caller-declared sources
remain unauthenticated, but replay and downstream audit retain the complete
declared gate-material lineage.
