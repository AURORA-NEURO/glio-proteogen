This package verifies a deterministic, signed typed downstream export over synthetic
caller-declared metadata. It retains field types, ownership, consent, support, compatibility,
seven uncertainty dimensions, provenance, limitations, canonical replay, and tamper detection.

consent validity, clinical utility, or production ABI approval.

## Safety controls

- Seven caller-declared controls are checked before export fields are traversed; malformed or
  denied controls fail closed.
- The exact provisional M17-06 input media type is required and is never relabeled or replaced.
- Export fields remain documented, typed, versioned, owned, and bound to source/evidence digests;
  no upstream disagreement is erased.
- Withheld consent, unsupported support, compatibility review, malformed inputs, or tampered
  results produce safe abstention or verification failure; absence is never converted to negative.
- The parent target is recorded but never emitted; kinase, generic all-omics, treatment, identity,
  and consent inference remain outside the output ceiling.
- Result provenance binds request configuration and explicit consent evidence digests in addition
  to source and field values, preserving the complete export input lineage for replay and audit.

The ABI is provisional and cannot self-approve. A governed release must review the exact source,
fixture, evaluator, benchmark, coverage, package, authority, and critical-finding evidence.
