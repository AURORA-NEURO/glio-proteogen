# M03-03 evidence inventory

This proportionate G0 package verifies deterministic admission of one synthetic protein-inference
source capsule. It checks genuine upstream closure, exact content bindings, bounded read-once file
admission, strict parsers, cross-reference integrity, context coherence, typed safe failure, and
interface parity. It does not establish laboratory execution, observed peptide or protein,
protein-group correctness, complex activity, biological validity, or clinical readiness.

## Locked risk controls

- All seven authorization controls are evaluated before source mapping traversal or I/O. Denial
  cannot be masked by a hostile mapping, invalid path, oversized set, or malformed source.
- Executable evidence reconstructs genuine M01-02, M03-01, and M03-02 results through their public
  operations. Exact embedded self-digests, bindings, identity graph, protocol, search space, and all
  M03-02 claims are revalidated. Valid upstream quarantine and abstention propagate before reads.
- The request maps governed roles to exact portable basenames under one directory. The mapping is
  closed and bounded before I/O. Absolute/directory/traversal/ADS names and symlink, junction, or
  reparse targets are rejected; each admitted regular file is read exactly once.
- The first version supports mzML, mzIdentML, three strict JSON manifest profiles, five distinct
  FASTA search-space component roles, PSI-MOD OBO, VCF, and GFF3. It deliberately has no mzTab or
  mzTab-M profile. Unsupported input cannot fall through to a permissive text or JSON parser.
- Transport and decoded bytes have independent length and SHA-256 bindings. Gzip is recognized by
  magic bytes. Corruption, raw/decoded mismatch, unsupported profile/version, structural failure,
  and dangling references remain separately auditable.
- JSON duplicate keys, unknown fields or terms, scalar coercion, silent defaults, and malformed or
  dangling references fail closed. Parsing extracts only structural diagnostics and content
  bindings; biological observations are not copied into the result.
- Canonical, decoy, conditional-isoform, variant, and contaminant FASTA roles and PSI-MOD ontology
  digest close exactly over M03-01. Labels and filenames are non-authoritative.
- The bundle and source index avoid a digest cycle: the bundle declares the digest of a manifest
  over the other sources, while the request's complete source index separately binds the bundle.
  The admission capsule binds both values and the exact parent receipt.
- Search build, VCF/GFF3 assembly, CV, and unit declarations remain distinct. Mismatch quarantines;
  missing or unsupported required context abstains. Neither outcome becomes a negative biological
  finding.
- Failure precedence is deterministic without erasing safe-to-retain downstream disagreement.
  The module never resolves conflicting biology, rewrites upstream identity, repairs malformed
  content, drops evidence, or promotes a caller label over content-addressed truth.
- The source cap is 64 and the sixty-fifth declaration is rejected before reads. Additional parser,
  record, decoded-byte, nesting, diagnostic, and output caps are locked in executable contracts;
  their maximum and first-excess boundaries must both run.
- Semantic ordering cannot change the complete result. Typed/dict/strict-JSON and bytes/read-once
  stream surfaces agree. Nested self-consistency checks reject derived-value forgery even when the
  attacker recomputes an outer digest.
- Raw ingestion is exposed through the library, service, plugin, and CLI. HTTP provides exact
  installed schema GET routes only and deliberately has no raw-ingestion POST route.
- Recursive ownership/privacy checks exclude direct identifiers, raw identity tokens, peptide
  sequences, protein or activity assertions, subtype, proteotype, kinase state, fused interpretation,
  treatment advice, and clinical claims. A correction issues a new superseding capsule; it never
  mutates prior evidence.

## Preregistered synthetic criteria

The locked corpus contains exactly eight scenario groups and 77 unique case identifiers, allocated
7/11/8/8/7/7/16/13. Every named case must execute and no parameterized oracle may silently omit a
declared case. The canonical source set must be admitted reproducibly, preserve exact upstream and
source-manifest receipts, and remain completely equal after semantic reordering and across public
surfaces.

All bytes are small, synthetic, and non-clinical. Identifiers are opaque and examples contain no
observed peptide sequence, real accession assignment, patient fact, raw abundance, activity score,
or treatment information. Acceptance proves deterministic software behavior within the declared
profile only. Authorities, filenames, digests, reference versions, source-directory custody, and
upstream assertions remain caller- or governance-declared unless independently attested elsewhere.

Recovery requires correction of the governed source, execution of a new immutable upstream result
when that boundary changed, and creation of a new admission request and capsule with explicit
supersession provenance. Critical disagreement, source substitution, override, claim promotion,
novel use, release exception, or unresolved biological conflict requires external human review.
