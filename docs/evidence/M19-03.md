# M19-03 evidence inventory

This G2 package verifies the bounded fusion and aggregation engine beneath
Immunopeptidomic evidence. It integrates caller-declared component-specific
proteotype evidence while retaining source identity, reliability, uncertainty,
ownership, and disagreement. It does not authenticate upstream content, infer
identity or consent, erase conflicts, produce kinase state, fuse generic all-omics,
or recommend treatment.
