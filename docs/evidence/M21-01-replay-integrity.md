# M21-01 replay integrity

M21-01 replay now re-curates the bound complex-activity reference-truth
request and compares the complete canonical result. Evidence, package content,
support, provenance, limitations, and status cannot be changed and then made
valid by serializing the forged result or recomputing its digest.

The module remains caller-declared benchmark material. It does not authenticate
source authority, inspect raw scientific payloads, infer complex-activity
biology, or emit a biological conclusion. Replay mismatches fail closed across
the service, API, CLI, and plugin boundaries.
