# M26-03 release and implementation evidence

M26-03 is a provisional ML-engineering/G1/S3 reproducible pipeline orchestrator
beneath `protein subtype`. Authority is restricted to dossier SHA-256
`sha256:0a6b200cbe073db13a4bcf315edc23ab97edfe6f500bc7ea2785f5e1c70da181`,
exact slice `GLIO-PROTEOGEN_240_Module_Dossier.md:9124-9164`. The endpoint and

## Delivered surface

The implementation is intentionally caller-declared and fail-closed. It
provides locked workflow contracts, dependency-closed acyclic DAG validation,
deterministic topological scheduling, container/resource declarations,
checkpointed attempts, seven-control authorization preflight, media-only M26-01
and M26-02 boundaries, environment capture, replay/tamper verification,
reproducible package manifests, seven explicit `NOT_ESTIMABLE` uncertainty
dimensions, human-review marking, strict service/FastAPI/Typer adapters, and an
opaque parse-once plugin token. It never emits a protein subtype estimate,
identity or consent inference, kinase activity, all-omics fusion, treatment
recommendation, or unsupported-negative finding.

Replay verification is mandatory even though the engine, service, and plugin
retain a legacy `replay` keyword for call-site compatibility. Passing
`replay=False` is rejected rather than degrading to payload-digest-only
validation: a digest proves only that an envelope is internally consistent,
while deterministic regeneration from the bound workflow request is required
to reject a re-signed semantic mutation. The adversarial suite covers this
exact forged-finding case.

Python implementation/evidence surface: **2,310 lines across 21 Python files** in the
M26-03 contract, runtime, eval, adversarial, interface, release, and tooling
paths. The complete branch delta from the M25-08 stack base is **2,809 added lines**.
