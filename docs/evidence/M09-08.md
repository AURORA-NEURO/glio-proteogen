## Gate interpretation

This is a provisional G3/S2 platform-engineering gate. Passing tests, evaluator, coverage, and
benchmark are not scientific validation and cannot authorize owner-sensitive ontology, model,
clinical, kinase, all-omics, treatment, or release claims. Authenticated issuers, owner review,
and a frozen ABI remain release prerequisites.
