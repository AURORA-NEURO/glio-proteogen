M14-02 is owned by Data engineering under S2/G1. It emits only typed context profile and
applicable mechanism set for `protein_subtype`. It has no KINOPHOS kinase ownership, generic
all-omics fusion, treatment recommendation, identity inference, consent inference, parent
mutation, or disagreement-erasure authority. Unsupported or conflicting context remains a
typed abstention requiring review.
