# M01-03 evidence inventory

This is a proportionate G0 evidence package for a deterministic ingestion boundary. It does not
self-issue reviewer approval. Every fixture is synthetic and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario matrix | `tests/fixtures/m01_03/scenarios.json` and its listed files | fixture digests, byte sizes, expected outcomes, safe facts, and diagnostics are exact |
| Focused invariants and boundaries | M01-03 property, policy, contract, and parser tests | bytes/stream determinism, extension independence, checksum, compression, limits, and output minimization |
| Executable eval | `evals/m01_03/run.py` | replays the locked matrix and emits machine-readable pass/fail evidence |
| Microbenchmarks | `benchmarks/m01_03_ingestion.py` | four representative public-boundary latency checks with broad CI budgets |
| Traceability | `docs/traceability/M01-03.csv` | each requirement names executable evidence |
| Reviewer sign-off | protected release review | supplied by a governed reviewer, never by implementation or test code |

## Locked risk controls

- The raw digest binds the exact supplied bytes. An expected checksum is verified before any
  decompression or parsing work.
- Gzip is selected by magic bytes, not a filename. Raw and decoded byte ceilings are independent;
  corrupt or excessive streams are quarantined with typed diagnostics.
- Content detection is closed. Exactly one supported profile is required; unknown, ambiguous,
  malformed, and unsupported inputs are never coerced into a nearby format.
- XML parsing rejects malformed documents and external-entity constructs. Text parsers apply
  profile-specific structural checks and bounded counts.
- Results retain only the detected profile/version and one bounded structural record count. Raw
  spectra, sequences, rows, variants, genotypes, attributes, direct identifiers, and other
  reusable scientific content are absent.
- Filename changes and byte-versus-stream delivery cannot change a content-derived result.
- Missing evidence stays missing. The parser cannot infer identity or consent, erase disagreement,
  or create a negative biological finding.
- The closed output cannot contain proteotype interpretation, kinase activity, generic fusion,
  treatment recommendation, or upstream mutation commands.

## Recovery and review

Recovery means resubmitting the unchanged retained source artifact under the same reviewed
contract and limits, verifying the raw digest, and comparing the deterministic result. A repaired
or transcoded source is a new artifact with a new digest; it never replaces prior evidence. A
critical discrepancy, support override, release exception, or unresolved conflict requires
governed human review.

```bash
uv run python -m evals.m01_03.run
uv run pytest benchmarks/m01_03_ingestion.py --benchmark-only --no-cov
uv run pytest
```
