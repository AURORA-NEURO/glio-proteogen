# M18-04 evidence inventory

This G3 package verifies bounded intended-use adaptation beneath Spatial proteomics
projection. It operates on caller-declared biomarker-panel evidence and does not authenticate
upstream content, infer identity or consent, estimate biology, or produce treatment guidance.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Authority-bound contract | `src/glio_proteogen/contracts/m18_04/` | dossier SHA/slice, strict provisional schemas, parent and safety ceiling |
| Locked scenario corpus | `tests/fixtures/m18_04/scenarios.json` | eight scenarios, authority metadata, eight adversarial cases, ≥95% target |
| Runtime/adversarial tests | `tests/contract/`, `tests/modules/` | seven-control preflight, policy branches, safe abstention, replay closure |
| Interface tests | `tests/integration/test_m1804_interfaces.py` | schema GET, API adapt/verify, CLI parity, no-overwrite and plugin descriptor |
| Executable evaluator | `evals/m18_04/run.py` | declared-oracle execution and 8/8 adversarial coverage |
| Microbenchmark | `evals/m18_04/benchmark.py` | ten deterministic public adapter calls and provisional budgets |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M18-04.csv` | dossier requirements mapped to implementation and evidence |
| Release verifier | `tools/verify_m1804_release.py` | evaluation, benchmark, coverage, package and import evidence |
