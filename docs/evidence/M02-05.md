# M02-05 evidence inventory

This is a proportionate G1 package for deterministic screening of synthetic identification-QC
signals. It neither self-issues reviewer approval nor claims scientific qualification.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenarios | `tests/fixtures/m02_05/scenarios.json` | exactly eight clean, seeded, abstention, mask, determinism, and authorization cases |
| Contract/module tests | M02-05 focused tests | strict shapes, profile binding, rule semantics, mask, provenance, and safe failure |
| Executable eval | `evals/m02_05/run.py` | exact replay, seven-class seeded sensitivity, clean false exclusion, hostile preflight, canonical equality, and privacy |
| Broad benchmark | `benchmarks/m02_05_artifact_detection.py` | representative public batch latency tripwire |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M02-05.csv` | requirement-to-evidence mapping |

## Locked risk controls

- Authorization of all seven upstream controls precedes signal traversal.
- Rules are closed over the pinned profile; no unreviewed class or signal is substituted.
- Required missing/not-applicable signals and any unsupported/OOD signal remain non-evaluable and
  require review. The OOD fixture uses an optional rule to prove unsupported evidence cannot become
  zero, clear, absence, or a biological negative.
- Triggered posteriors aggregate by maximum configured value only; they are not calibrated or
  learned probabilities.
- Exclusion requires the configured threshold and eligibility. The mask contains each target at
  most once even when several classes trigger.
- Reordering rules, signals, profile requirements, or evidence cannot alter the canonical output.
- Output is metadata-only and cannot contain raw spectra or peptide rows, subtype interpretation,
  kinase activity, omics fusion, upstream mutation, or treatment advice.

## Preregistered synthetic criteria

The fixture seeds one target/class pair for each of the seven artifact classes. Sensitivity is the
fraction of those seven pairs receiving `exclude`; the locked minimum is `0.95` and expected replay
is `1.0`. False-exclusion rate is the fraction of labeled clean targets appearing in the exclusion
mask; the locked ceiling is `0.05` and expected replay is `0.0`. A multi-class target is counted by
target/class for sensitivity and once in the mask.

These checks establish deterministic behavior for one synthetic fixture and pinned rule profile
only. They do not estimate real-world sensitivity, specificity, prevalence, predictive value,
posterior calibration, assay validity, biological validity, or clinical performance.

Recovery means correcting the authoritative signal, profile, rule, policy, or upstream control and
rerunning. Prior evidence is not rewritten. Critical discrepancy, novel/OOD state, support override,
claim promotion, and release exception require governed human review outside M02-05.

```bash
uv run python -m evals.m02_05.run
uv run pytest benchmarks/m02_05_artifact_detection.py --benchmark-only --no-cov
```
