## Locked safety and claims ceiling

- Feature values have explicit observed, missing, not-applicable, unsupported, and unknown states;
  non-observed values abstain and never become negative scientific findings.
- The executable invariant library accepts only a closed scalar/categorical comparison grammar;
  malformed or incompatible expressions become typed not-evaluable abstention.
- Domain, unit, category, feature identity, invariant references, migration version, and strict
  cardinality constraints are machine-validated.
- Seven caller controls are checked before schema, value, or source-artifact traversal. Denied
  controls fail closed with no reflected payload.
- Request and result digests are recomputed on replay; tampered derived regions are rejected.
- Result preserves parent target `biomarker_panel`, support, seven uncertainty dimensions,
  provenance, evidence, and limitations while emitting no biomarker panel, subtype, kinase state,
  treatment recommendation, or generic all-omics fusion.
- Every schema is marked `provisionalAbi=true` and `pendingOwnerConfirmation=true`.

## Synthetic regression criteria

The six-case matrix requires one valid result, one invalid hard-invariant result, three safe
abstentions, and one pre-execution authorization rejection. The evaluator replays every result
case through typed and JSON boundaries and adds a result-digest tamper check. These checks establish
implementation behavior only; they do not establish estimator accuracy, calibration, 90% coverage,
robustness, distribution-shift tolerance, biological validity, clinical utility, or release
qualification.

## Commands

```bash
uv run python -m evals.m06_01.run
uv run pytest -o addopts='' --no-cov benchmarks/m06_01_formal_state.py --benchmark-only
uv run python tools/verify_m06_01_package.py --wheel dist/<candidate>.whl
```

A release workflow may install the candidate wheel into a clean interpreter and run the package
verifier without `PYTHONPATH` to prove non-editable package import and schema closure.
