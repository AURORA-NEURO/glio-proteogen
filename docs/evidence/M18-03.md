# M18-03 evidence inventory

This G2 package verifies component-specific evidence fusion, source attribution, reliability
controls, disagreement preservation and safe failure over synthetic, non-clinical declarations.
It does not authenticate upstream content, identity, consent, measurements, model output,
biological truth or treatment decisions.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Authority-bound contract | `src/glio_proteogen/contracts/m18_03/` | exact dossier SHA/slice, strict provisional schemas, parent and safety ceiling |
| Locked scenario corpus | `tests/fixtures/m18_03/scenarios.json` | eight scenarios, authority metadata, eight adversarial cases, ≥95% target |
| Runtime/adversarial tests | `tests/runtime/test_m18_03_fusion.py` | attribution, resolved/open disagreement, reliability, ownership, controls, media and replay |
| Interface tests | `tests/integration/test_m18_03_interfaces.py` | schema GET, API POST, CLI fuse/schema parity, plugin descriptor |
| Executable evaluator | `evals/m18_03/run.py` | declared-oracle execution and 8/8 (100%) adversarial coverage |
| Microbenchmark | `evals/m18_03/benchmark.py` | one warm-up plus 25 public fusion calls and mean/p95 budgets |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M18-03.csv` | dossier requirements mapped to implementation and evidence |
| Data/model manifest | `docs/modules/GLIO-PROTEOGEN-M18-03.manifest.md` | synthetic metadata, zero executed models, no external traversal |
| Review / recovery | governed external process | reviewer authentication, exceptions and append-only recovery remain external |

```text
uv run pytest tests/contract/test_m18_03_provisional.py tests/runtime/test_m18_03_fusion.py tests/integration/test_m18_03_interfaces.py tests/evaluation/test_m18_03_evidence.py --no-cov
uv run python -m evals.m18_03.run
uv run python -m evals.m18_03.benchmark
```
