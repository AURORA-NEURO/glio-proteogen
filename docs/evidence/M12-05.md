## Gate interpretation

The suite passes the provisional engineering gates. The measured benchmark is
software latency only; it is not a scientific performance or calibration
claim. Supported uncertainty probability is an explicit local metadata
placeholder and not a population coverage guarantee. Owner review, endpoint
and catalogue freeze, calibration evidence, synthetic truth, and
negative-control qualification remain required before ABI promotion.

## Risk controls

Seven caller controls are inspected before objective parsing. Artifact
references are never dereferenced. Temporal order is validated before model
execution, and future values are not read. Unsupported objectives and
out-of-support change points are quarantined without emitting a negative
finding. Canonical replay and tamper verification provide recovery evidence;
failed verification is a safe error, not a best-effort repair.
