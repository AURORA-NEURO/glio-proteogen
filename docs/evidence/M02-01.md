# M02-01 evidence inventory

This is a proportionate G0 evidence package for deterministic validation of one pinned synthetic
peptide-identification metadata profile. Every fixture is synthetic and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario corpus | `tests/fixtures/m02_01/scenarios.json` | canonical conformance, mandatory fields, controlled terms, units, cardinality, compatibility, unresolved state, and consent-first rejection |
| Core correctness tests | M02-01 contract and validator tests | strict profile binding, closed findings, conditional applicability, canonical output, and safe failure |
| Executable eval | `evals/m02_01/run.py` | exact eight-case replay, deterministic digest/order, and recursive output-boundary checks |
| Microbenchmark | `benchmarks/m02_01_metadata_validation.py` | one broad representative public batch-validator latency tripwire |
| Traceability | `docs/traceability/M02-01.csv` | each requirement names executable evidence |
| Ontology, assay, and clinical qualification | external governed processes | explicitly outside the module and this evidence package |

## Locked risk controls

- Authorization and upstream controls are checked before metadata traversal.
- Requests bind to one exact protocol-profile identifier and version.
- Mandatory fields, terms, units, and cardinality are strict; no free-text inference or silent
  coercion repairs an invalid record.
- Assay/specimen compatibility is evaluated against pinned rules and never silently reconciled.
- Conditional applicability distinguishes accepted `not_applicable` from an incompatible use of
  that state on a required field.
- Mandatory unresolved values remain explicit and quarantine the record; they never become
  negative findings.
- The result is closed and excludes raw spectra/sequences, peptide calls, protein subtype,
  kinase activity, fused interpretation, treatment advice, and clinical claims.

## Synthetic regression criteria

The locked corpus contains exactly eight cases. The conformant case fixes one small metadata
object and its expected conformance. Each negative or quarantined case changes one declared
boundary. The conditional-compatibility case contains a paired assertion: reagent
`not_applicable` is accepted for label-free acquisition and rejected for the isobaric profile.
These checks establish deterministic implementation behavior only; they do not validate an
ontology, laboratory protocol, instrument measurement, peptide identity, biological conclusion,
calibration, or clinical use.

## Recovery and review

Recovery means correcting the source metadata or selecting a newly governed profile version,
then rerunning validation without mutating the original evidence. Critical discrepancies,
unresolved mandatory values, compatibility exceptions, support overrides, and claim promotion
require governed external review.

```bash
uv run python -m evals.m02_01.run
uv run pytest benchmarks/m02_01_metadata_validation.py --benchmark-only --no-cov
```
