# M05-07 evidence inventory

This is a local-only, provisional G1 evidence package for deterministic PTM-localization
support and unsupported-case abstention routing. The fixture corpus is synthetic and
non-clinical. The implementation ABI remains provisional because the dossier specifies the
behavioral boundary but does not confirm implementation-level names or transports.

## Locked safety and claims ceiling

- All eight support dimensions are closed and evaluated in canonical order.
- Outside-domain, missing, and unknown declarations abstain with typed reason and remediation;
  they never become negative scientific findings.
- Multiple failures retain the canonical union of unsupported dimensions and remediation paths.
- The seven caller-declared controls are checked before policy, prerequisite, or fact traversal;
  denied controls and an unreleasable M05-06 prerequisite fail closed.
- Request/result/receipt digests are recomputed on replay, and tampered derived fields or extra
  request fields are rejected.
- The result preserves parent target, uncertainty, support, provenance, evidence, and limitations
  while emitting no variant peptide, proteotype, PTM conclusion, treatment advice, or raw payload.
- The package carries `provisionalAbi=true` and `pendingOwnerConfirmation=true` in every schema;
  this checkpoint is not an ABI authority decision.

## Synthetic regression criteria

The seven-case corpus requires one supported route, eight isolated unsupported routes, unknown and
missing abstentions, a multiple-failure union, and two pre-route rejection cases. The evaluator
replays every case and two tamper checks, reporting the locked corpus digest. These checks establish
implementation behavior only; they do not validate real-world support-domain completeness,
scientific truth, cohort coverage, calibration, transportability, or clinical utility.

## Commands

```bash
uv run python -m evals.m05_07.run
uv run pytest -o addopts='' --no-cov benchmarks/m05_07_support_router.py --benchmark-only
uv run python tools/verify_m05_07_package.py --wheel dist/<candidate>.whl
```

The source boundary is covered by the M05-07 interface tests. A release workflow may install the
candidate wheel into a clean interpreter, then run the package verifier without `PYTHONPATH` to
prove the non-editable install imports the same six schemas and runtime module.
