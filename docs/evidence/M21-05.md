## Replay closure

M21-05 keeps the provisional `replay` keyword for caller compatibility, but
the flag cannot disable deterministic re-evaluation. Verification first checks
the canonical result digest and then evaluates the embedded request again,
comparing the complete result projection. This rejects a semantic mutation
that updates both request and result digests while leaving derived report,
findings, provenance, or support fields stale. Adversarial coverage exercises
that self-rehashed mutation with `replay=False`.
