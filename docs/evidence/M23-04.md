# GLIO-PROTEOGEN M23-04 evidence

M23-04 is a provisional external-transport evaluator beneath the
variant-peptide parent. It evaluates caller-declared mass-spectrometry
proteome, genome/transcriptome, PTM annotation, and benchmark material across
site, laboratory, platform, treatment era, population, disease class, and
specimen dimensions. It emits a transportability report only when calibrated
support remains; incomplete or unsupported transport safely abstains without
turning unsupported material into a negative or a biological estimate.

Authority is the permitted dossier SHA-256
`sha256:0a6b200cbe073db13a4bcf315edc23ab97edfe6f500bc7ea2785f5e1c70da181`,
exact slice `GLIO-PROTEOGEN_240_Module_Dossier.md:8088-8128`. The ABI remains
`0.1.0-provisional`; ownership is Computational biology, safety class S3, and
gate G3. The implementation has no M23-03 service import and keeps all
external source material and issuer authority caller-declared.

The contract closes request identity, exact four-artifact source binding,
unique seven-dimension validation/evaluation coverage, calibration-floor
status, support-domain narrowing derived from the exact evaluation statuses,
deterministic result identity, and replay digest. Runtime preflight requires
accepted configuration, resolved identity,
accepted provenance/quality/support/intended-use controls, and granted
consent. A missing transport dimension, no retained support domain, hostile
mapping, failed control, or replay mismatch fails closed with explicit
review-required abstention.

Strict FastAPI, Typer, and parse-once plugin interfaces expose validation,
evaluation, schema, and replay verification with sanitized errors and
no-overwrite behavior. The frozen evaluator covers eight scenarios, including
supported transport, domain narrowing, non-evaluable abstention, authorization,
source binding, specimen boundary, replay tamper, and determinism. The
adversarial suite covers malformed JSON, duplicate dimensions/artifacts,
control substitution, report/result closure, API/CLI failures, and forged
plugin tokens.
