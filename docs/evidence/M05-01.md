## Acceptance evidence

The contract exposes exactly 13 JSON Schema 2020-12 documents. All mandatory identity, version,
unit, cardinality, compatibility, unresolved, and parent-handoff declarations are explicit; there is
no undocumented optional scientific payload. Strict JSON rejects duplicate keys, coercion, unknown
members, non-finite values, and request bodies above 4 MiB.

Every valid result embeds the exact request and deterministically rederives all identifiers, digests,
findings, status, disposition, receipt, support, uncertainty, provenance, evidence, limitations,
review state, and time. Re-signed derived-region substitutions reject. Semantic-set reordering
retains complete request/result equality.

Authorization tests deny each of seven controls without touching protocol/profile traps. Dict-family
access uses built-in operations after exact-key and size scans; arbitrary mappings and accessors are
not invoked. Ordinary exceptions are sanitized and `BaseException` propagates. Plugin tokens require
issuance registry membership, original request identity, and exact byte snapshot.
