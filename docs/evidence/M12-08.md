## Gate interpretation

The suite passes the provisional engineering gates. The measured benchmark is
software latency only; it is not a scientific performance or calibration
claim. Supported uncertainty probability is an explicit local metadata
placeholder and not a population coverage guarantee. Owner review, endpoint
and catalogue freeze, calibration evidence, synthetic truth, and
negative-control qualification remain required before ABI promotion.

## Risk controls

Seven caller controls are inspected before architecture parsing. Artifact
references are never dereferenced. The chain validator requires every link
kind, explicit counter-evidence, a validation route, a locked configuration,
and a claim ceiling. Unsupported architectures and unsafe support metadata are
quarantined without emitting a negative finding. Canonical replay and tamper
verification provide recovery evidence; failed verification is a safe error,
not a best-effort repair.
