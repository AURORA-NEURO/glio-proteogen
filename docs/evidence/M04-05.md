## Locked controls

- Seven-control preflight completes before upstream or ledger access, uses built-in container
  operations, bounds key scans, rejects arbitrary mappings/BaseModels, sanitizes ordinary
  exceptions, and lets `BaseException` escape.
- The exact full M04-04 result is replayed once. Issued weak capabilities and plugin tokens bind
  exact identity plus canonical full snapshots; copied seals and stale digest-field mutations
  reject.
- Profile selection closes both M04-04 version and configuration digest. Unsupported version,
  assay/specimen/unit/applicability configuration, or upstream abstention returns typed abstention
  before ledger traversal.
- A stale quality-result binding produces a compact quarantined receipt without touching events.
  A correctly bound ledger enforces exact structure, all seven classes per target, self-digest,
  evidence, counts, and chronology.
- Missing, unsupported, and not-applicable events remain indeterminate with no numeric score.
  Clear requires an observed event below threshold. Absence of flags/mask never means negative.
- Every M04-05-owned artifact ID is `evidence.<64hex>` with exact owned MIME. Nested canaries reject
  without reflection through library, API, or CLI. Conflicting evidence identity reuse rejects.
- Result validation rederives every derived region and content-bound identifier. Semantic reorder
  equality holds; fully re-signed disposition, review, support, and time forgeries reject.
- All output-authority flags are false. No raw/external content, identity, consent, biological
  output, discordance, kinase, fusion, treatment, upstream mutation, or model execution is emitted.
- JSON is duplicate-free, strict, capped before decode, and parsed once. Sealed API/CLI/plugin
  execution does not replay upstream or ledger twice. CLI publishes only a new atomic file.
- Recovery is immutable and append-only through explicit supersession.
