M22-05 emits caller-declared subgroup evidence only. It does not authenticate
source truth, infer biology, emit a protein-RNA discordance conclusion, or
provide treatment/kinase/identity claims. Generated coverage, build, and
installation outputs are excluded from the committed source tree.

Replay is bound to the request embedded in the result. The engine validates
the envelope, regenerates the deterministic subgroup evaluation, and compares
the complete canonical result projection. A caller cannot make a changed
report, finding, support rationale, provenance, evidence, limitation, review
flag, or abstention reason appear valid merely by recomputing `result_digest`.

The request also requires the retained source artifact carrying the upstream
M22-04 result to match the upstream reference by its complete content-addressed
identity (artifact ID, version, digest, and media type). Reusing an upstream
artifact ID with a different digest or media type is rejected before evaluation,
so the provenance list cannot silently point at different source content.

Provenance also binds every artifact digest referenced by the request's nested
performance, calibration, coverage, and locked-configuration evidence. The
caller-declared evidence remains unauthenticated, but replay and downstream
audit now retain the complete declared evidence lineage rather than only the
top-level source-artifact list.
