# M01-08 evidence inventory

This is a proportionate G1 evidence package for deterministic release packaging. It does not
self-sign, attest, qualify a supply chain, or issue reviewer approval. Every fixture is synthetic
and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario corpus | `tests/fixtures/m01_08/scenarios.json` | three-artifact replay, exact manifests, integrity/path rejection, receipt blocking, and consent denial |
| Core correctness tests | M01-08 contract and engine tests | bounded byte verification, canonical paths/order, package digest, receipt binding, provenance, and failure semantics |
| Executable eval | `evals/m01_08/run.py` | exact scenario replay, bit reproducibility, order determinism, and output-boundary checks |
| Microbenchmark | `benchmarks/m01_08_release_packaging.py` | one broad representative public-engine latency tripwire |
| Traceability | `docs/traceability/M01-08.csv` | each requirement names executable evidence |
| Reviewer/signature authority | external governed systems | referenced by receipt only; never supplied by implementation or tests |

## Locked risk controls

- Consent and upstream controls are checked before source-byte access or hashing.
- Canonical relative member paths are unique and reject absolute or traversal forms.
- Every artifact byte count and SHA-256 digest must exactly match its declaration.
- Manifest ordering and package bytes are independent of input declaration/map order.
- Software, references, transformations, quality/support decisions, and numerical tolerances are
  exact declared manifest content rather than inferred metadata.
- External signature receipt is required and must bind the candidate package; missing or mismatch
  blocks/quarantines release, and the module never self-signs.
- The typed result cannot contain artifact bytes, raw spectra/sequences, keys, inferred
  proteotype, kinase activity, fused interpretation, treatment advice, or upstream scientific
  payloads. The controlled archive payload is returned separately and checked byte-for-byte.

## Synthetic regression criteria

The locked fixture contains exactly three tiny artifacts and an explicit oracle for member paths,
byte lengths, SHA-256 digests, package bytes/digest, manifest fields, and receipt binding. Reversed
input order must be bit-identical. Negative fixtures each alter one declared boundary. These
checks establish deterministic implementation behavior only; they do not validate scientific
content, external signatures, provenance truth, reproducibility of upstream analyses, or
supply-chain security.

## Recovery and review

Recovery means replaying the unchanged declarations and bytes under the same packaging policy and
comparing the deterministic candidate. Any changed byte, digest, path, version, reference,
transformation, decision, tolerance, or receipt creates a new request/result. Blocked candidates,
receipt discrepancies, overrides, and release exceptions require governed external review.

```bash
uv run python -m evals.m01_08.run
uv run pytest benchmarks/m01_08_release_packaging.py --benchmark-only --no-cov
```
