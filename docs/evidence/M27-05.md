## Safety and replay assertions

- Approved configuration, identity lineage, provenance, consent, quality, support, and intended-use
  controls are checked before telemetry traversal.
- The request identity is bound to the execution-context identity before those controls or any
  telemetry inputs are traversed; mismatched context/request IDs abstain fail closed.
- Unknown fields, duplicate IDs, non-finite metrics, invalid chronology, hostile tokens, stale
  digests, and output overwrites fail closed with sanitized boundary errors.
- Results carry seven explicit `not_estimable` uncertainty dimensions and retain evidence,
  provenance/control decisions, limitations, review requirement, and the provisional ABI marker.
- Provenance `input_digests` includes the bound M27-04 upstream artifact before source artifacts;
  the separate `configuration_digest` hashes the requested metric sequence and dashboard
  definitions, so upstream and telemetry-configuration drift cannot share a stale receipt.
- Emitted streams bind the exact requested metric sequence and derived stream identity, and
  dashboard definitions are retained exactly from the request before result replay or digest
  verification; rehashed duplicate/extra metrics are rejected.
- Request validation rejects dashboards that mention metrics outside the requested sequence, so
  retained dashboard definitions cannot overstate which operational signals were emitted.
- Unsupported M27-04 media types abstain without constructing a stream, dashboard, or alert.
- Supported requests that carry metric kinds/evidence but no observed values also abstain without
  fabricating samples, dashboards, or alert state; observed-value binding must be frozen before
  emission is enabled.
- API request/replay streams and direct service mappings enforce the declared 4 MiB request / 8 MiB
  result ceilings before strict validation, matching the already bounded CLI replay path.
- Package hashes and the release receipt require regeneration after this production behavior change;
  the inherited package record is not a final artifact receipt for this commit chain.
