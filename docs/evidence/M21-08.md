slice `GLIO-PROTEOGEN_240_Module_Dossier.md:7544-7584`.

Evidence is caller-declared and immutable by digest. The module requires
seven accepted controls, a bound M21-07 upstream artifact, retained M21-06
robustness evidence, complete requirements/benchmarks/risks/approvals/
obligations, and unique supporting evidence. A passing gate creates a signed
release record; any unmet criterion abstains with a finding and no release
record. No unsupported result is converted into a biological negative.

recomputes the adjudication from the bound request and compares the complete
canonical result, including release record, findings, support decision,
provenance, evidence, limitations, and abstention state. `replay=False` is
rejected explicitly, so a caller cannot self-rehash a forged release or
evidence payload and bypass regeneration.
