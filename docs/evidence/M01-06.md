# M01-06 evidence inventory

This is a proportionate G1 evidence package for deterministic control-median harmonization. It
does not self-issue reviewer approval. Every fixture is synthetic and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario corpus | `tests/fixtures/m01_06/scenarios.json` | technical-spread reduction, invariant retention, typed missingness, quarantine, and consent cases |
| Core correctness tests | M01-06 contract and engine tests | shift estimation, caps, invariant checks, canonical ordering, provenance, and failure semantics |
| Executable eval | `evals/m01_06/run.py` | exact scenario replay, order determinism, fixture metrics, and closed-output checks |
| Microbenchmark | `benchmarks/m01_06_harmonization.py` | one broad representative public-engine latency tripwire |
| Traceability | `docs/traceability/M01-06.csv` | each requirement names executable evidence |
| Reviewer sign-off | protected release review | supplied by a governed reviewer, never by implementation or test code |

## Locked risk controls

- Only declared controls estimate technical shifts; biological samples do not train their own
  correction.
- Accepted harmonization requires non-increasing control-median spread within tolerance and must
  preserve all locked biological directions and ranks within tolerance. The supported fixture
  separately locks actual spread reduction.
- Missing and censored values remain distinct typed states and never become zero or imputed
  observations.
- Insufficient controls, capped shifts, excessive residual technical spread, and invariant
  failures quarantine rather than silently yielding an accepted object. A capped estimate and
  applied shift remain explicit in the manifest.
- Reordering observations or declarations cannot change canonical output.
- Output cannot contain raw spectra or sequences, upstream genomic/PTM payloads, inferred
  proteotype, kinase activity, treatment advice, or generic fused interpretation.
- Consent denial and unresolved identity/lineage fail before harmonization.

## Synthetic regression criteria

The locked supported fixture contains both batch and platform technical offsets. Its exact
control-median spread must decrease after harmonization, and every declared biological direction
and rank relation must be unchanged. Separate fixtures verify typed missing/censored retention
and each quarantine path. These are exact implementation checks over a tiny designed corpus;
they do not estimate real-cohort effect removal, biological-signal retention, calibration,
generalization, or clinical utility.

## Recovery and review

Recovery means replaying the unchanged content-addressed request under the same profile and
policy and comparing the deterministic result. A changed observation, stratum, control set,
cap, invariant, profile, or policy is a new request and result; prior evidence is not rewritten.
Insufficient controls, cap activation, biological conflicts, support overrides, and release
exceptions require governed human review.
