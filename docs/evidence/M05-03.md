## Locked risk controls

- Seven caller controls are inspected before any governed result, policy, artifact, byte mapping,
  or nested value. Every individual denial and arbitrary mapping is rejected with zero traversal.
  Built-in dict/subclass materialization bypasses overridden accessors; ordinary exceptions fail
  closed and `BaseException` is not swallowed.
- The request embeds the exact full public M05-02 result and strictly replays it, transitively
  replaying genuine M01-02 and M05-01. Context identity, quality-result, support-receipt,
  intended-use, configuration, policy, and chronology bindings close exactly. Compact receipts,
  handwritten substitutes, stale bindings, and re-signed upstream regions reject.
- Four canonical documents are created first. Their exact manifest references are installed into
  the genuine M05-02 claims before executing the public upstream chain. Document digests never
  include the M05-02 result digest, avoiding circular construction.
- A quarantined M05-02 result produces M05-03 quarantine, and an abstained M05-02 result produces
  M05-03 abstention, both with zero artifact mapping access. Only a reconciled result permits
  artifact traversal.
- The byte mapping is an exact built-in mapping of four closed roles to exact immutable `bytes`.
  Missing/extra roles, arbitrary mappings, `bytearray`, bytes subclasses, size mismatch, and
  digest mismatch reject before semantic diagnostics.
- Request, per-document, and total-document caps are enforced at 4 MiB, 8 MiB, and 32 MiB.
  Relevant caps precede JSON parsing and hashing. The maximum declared record count is a scalar
  declaration and never controls allocation.
- JSON ingress is duplicate-free, strict, and canonical. Malformed/noncanonical JSON, duplicate
  keys, unknown fields, coercion, and role/document mismatch reject. A structural/integrity error
  is never downgraded to a diagnostic.
- Exact role, claim, manifest, content reference, media type, document type, format/version,
  parser/version, identity, protocol, reference bundle, assay/specimen policy, intended use, unit,
  assay protocol, specimen processing, completeness, assay support, and parent quality checks
  remain separate and typed.
- All 17 diagnostic codes have one installed action. Duplicate content records and remains
  retained, the two non-evaluable conditions abstain, and every semantic mismatch quarantines.
  Quarantine wins over abstention. Diagnostics are unique by code and role, canonically ordered,
  and aggregate every comparison basis into one evidence digest; the maximum-discrepancy oracle
  produces a strict typed quarantine within the 60-diagnostic result cap.
- Quarantine retains all four successfully parsed typed documents. Abstention preserves metadata
  and never infers absence. No path mutates upstream results, claims, documents, manifest/content
  references, or source bytes, and no path deduplicates or selects an authoritative copy.
- The result carries typed parsed documents only, never raw bytes, rows, spectra, sequences,
  accessions, abundance values, PTM sites, or an external content artifact. Recursive privacy
  checks require the prohibited canary to be absent.
- Result validation rederives inputs, diagnostics, disposition, receipt, support, uncertainty,
  provenance, evidence, limitations, review, completion time, and result digest. Re-signed derived
  regions reject.
- The CLI accepts exactly four locked regular filenames, snapshots them once, rejects links,
  junctions, reparse points, missing/extra/nonregular sources, and refuses an existing or linked
  output. It writes a new output atomically with no reread or partial publication.
- Recovery is append-only. A corrected request explicitly supersedes the immutable prior result
  without overwrite, mutation, deletion, relabelling, deduplication, re-signing, or silent
  promotion.

## Contract and interface plan

The public registry exports exactly 12 JSON Schema 2020-12 names: request, output, policy,
parser-profile, input-artifact, proteome-document, genome-document, transcriptome-document,
ptm-document, validated-input, diagnostic, and receipt. Unknown names fail closed.

The Python boundary is `ingest_ptm_localization_raw_inputs`. HTTP exposes only
`GET /v1/contracts/M05-03/{name}/schema`; an execution POST is deliberately absent and must return
404 or 405. CLI exposes `ptm_localization-raw ingest REQUEST SOURCE --output RESULT` and
`ptm_localization-raw export-schema NAME`. The source names are exactly
`mass-spectrometry-proteome.json`, `genome.json`, `transcriptome.json`, and
`ptm-annotations.json`. Python and CLI share the exact authorization, request,
upstream replay, bytes, canonical JSON, typed result/error, and digest boundaries. No interface
accepts a looser request, bypasses preflight, follows links, rereads sources, overwrites output, or
opens external scientific content.

## Benchmark criterion

The benchmark builds four modest canonical documents and genuine public M01-02, M05-01, and
M05-02 outputs before measurement. One untimed public call verifies four validated inputs,
document/digest projection, diagnostics, evidence, limitations, parent context, false authority
flags, and determinism. It then measures exactly 25 public `ingest_ptm_localization_raw_inputs` calls;
upstream construction, document/request construction, serialization, imports, CLI startup,
filesystem access, HTTP transport, and reporting remain outside the timed boundary. The
nearest-rank p95 sample is used. Passing requires mean no more than 500,000,000 ns and p95 no more
than 750,000,000 ns.

The eval accepts the largest document constructible from the strict bounded metadata schema and
rejects a document at 8 MiB plus one byte. Because four documents capped at 8 MiB cannot isolate
a 32 MiB aggregate excess from an individual excess, the aggregate case asserts early cap
rejection without claiming aggregate-only precedence. These capacity cases are outside the
representative benchmark. Latency provides no evidence of parser truth, external content
validity, identity, protein/ptm_localization inference, model accuracy, uncertainty coverage,
calibration, robustness, distribution shift, biological validity, transportability, human
factors, or prospective use.
