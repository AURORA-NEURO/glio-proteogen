## Locked risk controls

- Seven controls are inspected before any governed request, upstream result, policy, profile, or
  ledger traversal. Dict-subclass overrides cannot bypass built-in access, arbitrary mappings
  reject without access, ordinary exceptions fail closed, and `BaseException` propagates.
- The request embeds and fully replays the exact public M04-03 result, transitively containing
  genuine M01-02, M04-01, and M04-02 outputs. Compact receipts and re-signed substitutes reject.
- A validated upstream requires one four-role ledger. Quarantined or abstained upstream results
  require no ledger and return before ledger access. Ledger self-digest mismatch rejects;
  semantic role/input/document binding mismatch quarantines with zero metrics.
- All counts close under their exact partitions and caps. Ratio values use only exact integer
  round-half-up at 1,000,000 ppm, and threshold status compares that rounded integer value. The
  2/3 boundary therefore equals 666,667 ppm. Zero denominators and non-observed states never
  become numeric zero or negative evidence.
- Detection-limit censoring is the only censored metric state, is present exactly with a positive
  below-limit count, and retains its exact ratio and censored count.
- Profiles cover all four roles with disjoint match domains. Each profile has eight exact
  directional thresholds; unsupported or ambiguous selection never yields a partial output.
- All four assay-quality objects and 32 metrics are retained during threshold quarantine. Safe
  failure, ledger-binding failure, and unsupported profiles emit zero role metrics.
- The 14 finding codes have exact actions. Quarantine outranks abstention and record-only findings.
  Optional warnings remain visible and limit support; required non-evaluable evidence abstains.
- Duplicate content and every M04-03 reference remain unchanged; no path deduplicates, repairs,
  relabels, clips, selects an authority, or mutates upstream objects.
- The result contains only typed aggregate facts and metrics. It contains no raw rows, filenames,
  secrets, canaries, biological identifiers, spectra, sequences, accessions, or external content.
- Results return exactly 12-45 current-layer evidence records, seven not-estimable uncertainty
  dimensions, two exact sensitivity notes, three limitations, false authority flags, and a fully
  rederived receipt and result digest.
- Role-fact input identifiers retain the exact opaque upstream `input.*` values. Conflicting
  content under one evidence identity/version rejects, receipt disposition derives from canonical
  finding codes, and no zero-digest sentinel is publicly valid.
- CLI parsing is duplicate-free and strict. The 4 MiB cap precedes decode, existing or linked
  output rejects, and publication is atomic to a new file.
- Recovery is append-only. Any corrected request supersedes but never overwrites, deletes,
  re-signs, relabels, or silently promotes prior evidence.

## Contract and interface plan

The registry exports exactly 13 strict JSON Schema 2020-12 names: request, output, policy,
threshold, assay-profile, fact-counts, fact-states, role-facts, fact-ledger, metric, assay-quality,
finding, and receipt. Unknown names reject.

The Python boundary is `compute_proteoform_quality_metrics`. HTTP exposes schema GET and metadata-
only POST `/v1/modules/M04-04/quality-metric-computation`. CLI exposes
`proteoform-quality compute REQUEST --output RESULT` and
`proteoform-quality export-schema NAME`. No interface accepts a looser request, bypasses
preflight, follows links, overwrites output, opens external scientific content, or uses floats.

## Benchmark criterion

The benchmark prepares a genuine upstream chain and maximum supported metadata shape—four roles,
32 profiles, 256 thresholds, four facts, 32 metrics, 45 evidence records, and three limitations—
outside measurement. One public warm-up is untimed. Exactly 25 public computation calls are timed.
Passing requires mean no more than 500,000,000 ns and nearest-rank p95 no more than 750,000,000
ns. Latency provides no evidence of measurement truth, model accuracy, calibration, biological
validity, transportability, human factors, or clinical utility.
