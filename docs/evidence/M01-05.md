# M01-05 evidence inventory

This is a proportionate G1 evidence package for deterministic artifact and contamination
detection. It does not self-issue reviewer approval. Every fixture is synthetic and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario corpus | `tests/fixtures/m01_05/scenarios.json` | seven-class seeded batch, clean controls, missing signal, and consent denial |
| Core correctness tests | M01-05 contract and engine tests | rule comparison, maximum posterior, decision threshold, eligibility, mask, and provenance invariants |
| Executable eval | `evals/m01_05/run.py` | exact scenario replay, seeded sensitivity, false-exclusion rate, order determinism, and output-boundary checks |
| Microbenchmark | `benchmarks/m01_05_artifact_detection.py` | broad representative public-engine latency tripwire |
| Traceability | `docs/traceability/M01-05.csv` | each requirement names executable evidence |
| Reviewer sign-off | protected release review | supplied by a governed reviewer, never by implementation or test code |

## Locked risk controls

- Detection is closed over reviewed target/class rules. Uncovered or missing signal cannot become
  a clear technical finding.
- Triggered rule posteriors aggregate by maximum only. They are not added, multiplied, or
  presented as a learned probability.
- Exclusion requires threshold satisfaction and exclusion eligibility on every triggered rule
  tied for the maximum posterior; an untriggered eligible rule cannot promote a result.
- Missing required signal remains non-evaluable and requires review.
- One target can carry several class flags, while the exclusion mask contains it at most once.
- Reordering targets, rules, or signals cannot alter canonical flags, decisions, or mask.
- The output cannot contain raw measurements, sequences, spectra, biological absence,
  proteotype interpretation, kinase activity, treatment advice, or upstream mutations.
- Consent denial and unresolved identity/lineage fail before artifact evaluation.

## Preregistered synthetic criteria

The labeled fixture contains at least one seeded target/class pair for each of the seven artifact
classes. Sensitivity is the fraction of those seven seeded pairs that receive the expected
exclusion decision; the locked minimum is `0.95` and the expected replay is `1.0`.
False-exclusion rate is the fraction of labeled clean targets covered by exclusion-eligible
rules that are present in the exclusion mask; the locked ceiling is `0.05` and the expected
replay is `0.0`. A target with multiple classes is counted by target/class for sensitivity and
once by target for false exclusion.

These locked checks establish deterministic implementation behavior on the fixture only. They do
not establish clinical performance, cohort generalization, prevalence-adjusted predictive value,
or probability calibration.

## Recovery and review

Recovery means replaying the unchanged content-addressed request under the same detector profile
and policy and comparing the deterministic result. A changed signal, rule, threshold, profile,
or policy is a new request and result; prior evidence is not rewritten. Missing signals, critical
discrepancies, support overrides, and release exceptions require governed human review.

```bash
uv run python -m evals.m01_05.run
uv run pytest benchmarks/m01_05_artifact_detection.py --benchmark-only --no-cov
uv run pytest
```
