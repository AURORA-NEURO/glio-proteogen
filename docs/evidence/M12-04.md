## Gate interpretation

The suite passes the provisional engineering gates. The measured benchmark is
software latency only; it is not a scientific performance or calibration
claim. The uncertainty probability on the supported path is an explicit local
metadata placeholder and not a population coverage guarantee. Owner review,
endpoint/catalogue freeze, calibration evidence, synthetic truth and
negative-control qualification remain required before any ABI promotion.

## Risk controls

Seven caller controls are inspected before method parsing. Artifact references
are never dereferenced. The result retains assumptions, alternatives, and
counter-evidence, and safe abstention is structurally free of estimates. The
runtime cannot emit kinase, fusion, treatment, identity, consent, or negative
claims. Canonical replay and tamper verification provide recovery evidence;
failed verification is a safe error, not a best-effort repair.
