# M02-02 evidence inventory

This is a proportionate G0 evidence package for deterministic auditing of synthetic
peptide-identification artifact bindings against one locked upstream identity resolution. Every
fixture is synthetic and non-clinical.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenario corpus | `tests/fixtures/m02_02/scenarios.json` | conformant bindings, swap, scoped-token collision, duplicate content, cross-patient, unresolved, unsupported, upstream unresolved, and consent preflight |
| Locked upstream inputs | `tests/fixtures/m02_02/upstream_resolved.json` and `upstream_unresolved.json` | strict static M01-02 resolution envelopes; no M01-02 solver or ledger runs during M02-02 evidence replay |
| Core and contract tests | M02-02 binding-audit tests | strict closure, upstream graph references, finding/disposition relations, no silent merge, and safe failure |
| Executable eval | `evals/m02_02/run.py` | exact eight-case replay, deterministic equality, privacy boundary, and authorization ordering |
| Microbenchmark | `benchmarks/m02_02_identity_bindings.py` | one broad representative public batch-audit latency tripwire |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M02-02.csv` | each requirement names executable evidence |
| Real identity, assay, biological, and clinical qualification | external governed processes | explicitly outside this module and evidence package |

## Locked risk controls

- Consent and generic upstream controls are checked before artifact bindings are traversed.
- Every request is bound to an exact upstream identity resolution and exact policy digest.
- Entity and subject components are reused from the upstream resolved graph; the module does not
  solve, merge, split, rename, or infer identity.
- Subject-set disagreement remains an explicit swap. Multiple patient components on a run or
  derived object quarantine as a cross-patient link.
- Opaque token digests are compared only within their declared scope; raw token material is never
  accepted or emitted.
- Duplicate content assignments preserve every source binding and choose no authoritative copy.
- Unresolved, unsupported, and upstream-unresolved evidence abstains rather than becoming a
  negative identity finding.
- The output excludes raw identifiers, raw token values, spectra, sequences, measurements,
  peptide calls, protein subtype, kinase activity, fused interpretation, and treatment advice.

## Synthetic regression criteria

The locked corpus contains exactly eight cases. Each nonconformant or abstaining case changes one
declared boundary from a small conformant reference. The token-collision case includes a
different-scope control; the final case pairs an upstream-unresolved result with a consent-denied
preflight assertion. The replay requires canonical full-result equality under irrelevant
collection ordering and checks that privacy canaries do not cross the public result.

These checks establish deterministic implementation behavior only. They do not validate a real
patient identity, chain of custody, laboratory assay, biological conclusion, transportability,
or clinical use.

## Recovery and review

Recovery means correcting the authoritative source binding or obtaining a new governed upstream
identity resolution, then rerunning the audit without changing the original evidence. Swaps,
collisions, duplicates, cross-patient links, unresolved bindings, support overrides, and release
exceptions require governed review outside M02-02.

```bash
uv run python -m evals.m02_02.run
uv run pytest benchmarks/m02_02_identity_bindings.py --benchmark-only --no-cov
```
