# M07-05 evidence inventory

This package records the provisional implementation of the mechanism and constraint integrator.
The authoritative dossier slice is behavioral: it requires hard constraints to hold, quantifies
soft conflicts, demonstrates ablation, declares uncertainty, versions the implementation, and
fails safely. It does not authorize a frozen ABI or a biological/clinical claim.

## Executed static gate

The standalone Ruff executable reports clean checks and formatting for the M07-05 contract,
runtime, transport, evaluator, benchmark, fixture, and focused test paths. Bundled Python 3.12.13
compileall and a manual harness passed 3 contract, 9 focused runtime, and 2 evaluator tests; the
bundled runtime does not include pytest or mypy. `uv build` is blocked because the managed Python
installation is unreadable (`Access is denied`), so wheel, coverage, and typed-project gates remain
pending and the release record must be regenerated in the governed project environment.

## Provisional ABI and limitations

Operation names, field names, media types, endpoints, capacity limits, and the deterministic hash
projection are implementation choices marked `provisionalAbi=true` in every exported schema. The
runtime deliberately emits no parent proteotype estimate and uses `NOT_ESTIMABLE` uncertainty for
all dimensions. It is a contract and safety harness, not a trained mechanism model or evidence of
biological validity.
