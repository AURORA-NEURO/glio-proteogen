# M02-03 evidence inventory

This is a proportionate G0 package for deterministic validation of synthetic identification raw
inputs. It reuses the already-tested M01-03 parser rather than claiming a second parser.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Locked scenarios | `tests/fixtures/m02_03/scenarios.json` | valid bundle, gzip, advisory extension, checksum, malformed content, missing role, role/format mismatch, and consent preflight |
| Shared parser fixtures | selected files under `tests/fixtures/m01_03` | exact mzML, mzIdentML, FASTA, VCF, GFF3, gzip, and malformed bytes |
| Contract/module tests | M02-03 focused tests | strict policy, authorization order, source closure, canonical output, and safe failure |
| Executable eval | `evals/m02_03/run.py` | eight-case replay, order equality, and recursive privacy scan |
| Broad benchmark | `benchmarks/m02_03_identification_ingestion.py` | representative public batch ingestion latency tripwire |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M02-03.csv` | requirement-to-evidence mapping |

Recovery means correcting or replacing the authoritative external bytes/metadata and rerunning.
Original evidence is not mutated. Critical discrepancies and release exceptions require governed
review outside M02-03. This package is candidate engineering evidence, not scientific or clinical
qualification.
