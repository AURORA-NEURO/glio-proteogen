## Explicit limits

M06-03 is provisional and does not establish measurement truth, calibration, probability,
biomarker-panel membership, identity, consent, treatment, clinical interpretation, external
content authenticity, or issuer authority. Benchmark latency is only a software regression signal.
No release verifier or governed workflow should treat this local-only package as production release
evidence until the ABI is formally frozen and reviewed.
