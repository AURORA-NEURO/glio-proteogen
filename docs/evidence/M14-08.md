# M14-08 evidence inventory

This release package verifies a deterministic mechanism evidence dossier over synthetic,
caller-declared references. It tests provenance, counter-evidence, validation-route closure,
claim ceilings, safe abstention, replay/tamper detection, strict interfaces, and packaging. It
does not authenticate evidence, dereference external content, run a scientific model, infer
identity or consent, or recommend treatment.

## Safety and authority controls

- Seven caller-declared controls are checked before typed request traversal. Rejected controls,
  arbitrary mappings, hostile attribute access, and token mismatch fail closed.
- The M14-07 result is bound by exact media type and retained as an opaque artifact reference;
  M14-08 does not dereference it or treat its digest as issuer authentication.
- Supported links require evidence; claims require both evidence and counter-evidence; every
  declared validation route must complete before review-ready publication.
- Unknown methods, unresolved links, required validation, and authorization failures abstain
  without fabricating a negative mechanism. Human review remains explicit.
- Result IDs and digests are derived from canonical request/result bytes. Reordered or tampered
  payloads cannot be silently repaired or promoted.
- The claim ceiling is carried into the dossier and limitations prohibit treatment, kinase,
  all-omics, identity, and consent interpretation.

## Reproducibility

The fixture digest, evaluator output, benchmark output, coverage totals, and package hashes are
stored under `release-evidence/m14_08/`. The verifier is standard-library only and can be run
with `uv run python tools/verify_m1408_release.py` after the wheel and sdist are built. A clean
worktree and isolated wheel import are required for publication.
