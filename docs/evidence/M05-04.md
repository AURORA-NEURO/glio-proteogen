## Locked risk controls

- Seven controls authorize before upstream or ledger traversal. Denials and arbitrary containers
  fail closed with zero ledger access.
- The exact full M05-03 result is replayed; all transitive identity, protocol, reference,
  assay/specimen, intended-use, result, receipt, and chronology bindings close.
- Validated upstream requires an exact four-role ledger. Quarantined/abstained upstream prohibits
  the ledger and emits zero metrics without access.
- Four roles, eight metric codes, 32 supported metrics, 4-32 profiles, eight thresholds per
  profile, and 12-45 evidence records form closed installed capacities.
- Counts are bounded integers with closed partitions. Ratios are exact round-half-up ppm. Missing,
  unsupported, indeterminate, not-applicable, and censored evidence cannot silently become zero.
- Required missing/unsupported/not-evaluable evidence abstains; binding/version/threshold and
  required-warning failures quarantine; optional warnings limit support; quarantine wins.
- Exact built-in container firewalls reject arbitrary mappings/sequences and subclasses. JSON is
  duplicate-free and strict, and ingress rejects the first byte above 4 MiB.
- Sealed admission and plugin tokens bind issuance, exact identity, canonical request bytes,
  embedded M05-03 identity/bytes, and derived digests. Mutation invalidates reuse.
- Result validation fully rederives every derived region and digest. Re-signed forgeries reject.
- All authority flags are false, seven uncertainty dimensions are not estimable, and exactly three
  limitations state the deterministic aggregate-only ceiling.
- Recovery is append-only and explicitly binds superseded result digests.

## Benchmark criterion

The benchmark constructs the genuine maximum 32-profile, 256-threshold, four-fact, 32-metric,
45-evidence workload outside measurement. It performs one untimed public warm-up and exactly 25
timed public `compute_ptm_localization_quality_metrics` calls. The report retains positive integer
samples, canonical request/result byte sizes, request/result digests, mean, median, nearest-rank
p95, maximum, and pass state. Passing requires request size within 4 MiB, mean <=500,000,000 ns,
and p95 <=750,000,000 ns. This is a software latency regression criterion only.
