# M17-01 evidence inventory

This G0 package verifies typed upstream contract resolution and safe failure over synthetic,
non-clinical declarations. It does not authenticate external content, identity, consent,
measurements, model output, biological truth, or treatment decisions.

| Evidence | Artifact | Verification |
| --- | --- | --- |
| Authority-bound contract | `src/glio_proteogen/contracts/m17_01/` | exact dossier SHA/slice, strict provisional schemas, parent and safety ceiling |
| Locked scenario corpus | `tests/fixtures/m17_01/scenarios.json` | five named scenarios, authority metadata, eight adversarial cases, ≥95% target |
| Runtime and adversarial tests | `tests/runtime/test_m17_01_resolver.py` | validated, abstained, unknown, typed rejection, control denial, tamper replay |
| Interface tests | `tests/integration/test_m17_01_interfaces.py` | schema GET, API POST, CLI schema/resolve parity, plugin descriptor |
| Executable evaluator | `evals/m17_01/run.py` | declared-oracle execution and 8/8 (100%) adversarial coverage |
| Microbenchmark | `evals/m17_01/benchmark.py` | one warm-up plus 25 public resolver calls and mean/p95 budgets |
| Traceability | `docs/traceability/GLIO-PROTEOGEN-M17-01.csv` | dossier requirements mapped to code and executable evidence |
| Data/model manifest | `docs/modules/GLIO-PROTEOGEN-M17-01.manifest.md` | synthetic metadata, zero executed models, no external traversal |
| Review / rollback | governed external process | reviewer authentication, release exception, and append-only recovery remain external |
