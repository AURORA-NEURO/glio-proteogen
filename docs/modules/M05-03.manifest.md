## Schema and interface manifest

The public registry exports exactly 12 strict JSON Schema 2020-12 contracts. Unknown names reject.
Schema metadata declares strict validation and the parent target; sets raw payload and external
content traversal false; and denies identity, consent, protein, ptm_localization, CN-regression,
discordance, kinase, fusion, treatment, persistence, and model authority. The closed result fields
and exact limitations additionally deny PTM and clinical inference.

Python exposes the bytes-aware `ingest_ptm_localization_raw_inputs` operation. HTTP exposes schema GET
only; an M05-03 execution POST is intentionally absent and must return 404 or 405. The CLI accepts
an explicit request file, locked source directory, and new output path. Python and CLI share strict
reconstruction, authorization, upstream replay, byte caps, duplicate-key/canonical JSON rules,
typed result/error semantics, and digests. No interface silently converts bytes or accepts a
looser model.

## Rollback and recovery

1. Stop publication or quarantine/abstain/reject at the boundary; do not overwrite source bytes,
   output, or prior evidence.
2. Retain the exact request, snapshotted document digests, typed documents when available,
   diagnostics/errors, upstream result, policy, parser profiles, evidence, and review record.
3. Restore configuration or inputs through the externally governed source; never repair,
   relabel, deduplicate, or reinterpret them inside M05-03.
4. Submit a corrected request that explicitly names the superseded result digest. Publish only to
   a new nonexistent output path.
5. Replay all 72 cases, interfaces, schemas, benchmark, privacy/authority checks, byte-boundary
   checks, traceability, and review against the corrected immutable version.

Supersession is append-only. It does not delete, mutate, re-sign, overwrite, or silently promote a
prior result or source artifact.
