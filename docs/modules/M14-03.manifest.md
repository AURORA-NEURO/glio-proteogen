## Safety and replay boundary

The constructor checks all seven upstream controls before traversing configuration or source
references. It requires complete feature lineage, a locked stoichiometry reference, unique
negative-control references, relation closure without self-loops, and the explicit deterministic
metadata replay family. Unsupported configuration families abstain with review-required support;
denied controls fail closed. Results contain seven not-estimable uncertainty dimensions,
provenance, evidence references, limitations, and a recomputed request/result digest.

The ABI is provisional because the dossier slice does not freeze the model family, feature value
semantics, or handoff details. The implementation freezes only the safe metadata boundary and
keeps architecture/model directions declared-but-not-executed pending Platform engineering
confirmation.

## Data, review, and recovery

Fixtures are synthetic and non-clinical. The module never reads artifact bytes, follows paths,
authenticates issuers, or repairs/relabels source disagreement. A governed release record must
bind the authority SHA, source commit, schema digests, fixture digest, evaluator report,
benchmark, wheel/install report, and external owner review. Corrections are append-only through a
new request and optional `supersedes_result_digest`; prior results are never overwritten.
