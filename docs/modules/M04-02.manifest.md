artifacts used by Proteoform/isoform inference. It never mutates upstream evidence, relabels
another module's output, erases disagreement, infers missing identity or consent, treats
unsupported evidence as negative, emits a proteogenomic state/proteotype/protein-level subtype,
claims KINOPHOS kinase ownership, performs generic all-omics fusion, recommends treatment, or
provides clinical decision support.

## Rollback and recovery

1. Quarantine, abstain, or reject the affected request without changing either upstream result or
   any artifact declaration.
2. Retain the immutable request, result or rejection evidence, physical graph, artifact DAG,
   policy, versions, findings, receipts, and all content digests.
3. Withdraw the affected policy or deployment through the external governed release process and
   restore the last approved version when operational rollback is required.
4. Correct the authoritative identity result, protocol result, policy, artifact claim, derivation,
   authorization source, or implementation and issue a new request with exact supersession.
5. Replay all 70 cases, eight schemas, interface parity, recursive privacy/authority checks, and
   the 25-call benchmark before release.
6. Bind new reviewer sign-off to the replacement and retain the prior result. Never delete,
   rewrite, re-sign, relabel, deduplicate, silently promote, or select authority among old evidence.
