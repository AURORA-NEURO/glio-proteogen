# M10-07 — Calibration and selective prediction (provisional)

M10-07 is the calibration/selective-prediction boundary beneath pathway and
proteotype factors. It calibrates a caller-declared protein/RNA discordance
estimate by site, platform, disease class, and subgroup, then returns a typed
estimate, prediction set, support decision, uncertainty profile, provenance,
evidence, and limitations.

## Authority and ABI status

The implementation is derived from the permitted dossier slice **3540–3583**
at SHA-256
`0a6b200cbe073db13a4bcf315edc23ab97edfe6f500bc7ea2785f5e1c70da181`.
The dossier describes behavior and ownership, not a frozen public catalogue,
endpoint, media-type registry, or metric ABI. Every exported surface therefore
uses `0.1.0-provisional`, carries `provisionalAbi: true`, and remains subject
to owner confirmation.

## Contract and safety boundary

- Requests bind exactly one provisional M10-06 uncertainty artifact, a locked
  calibration configuration, at least one source artifact, execution identity,
  consent, provenance, quality, support, intended-use, and approved-configuration
  controls.
- Calibration scopes require unique `(site, platform, disease_class, subgroup)`
  tuples. The provisional target is nominal 90% selective coverage with an
  85–95% review envelope.
- Results include all seven kernel uncertainty dimensions and never emit a
  parent protein/RNA discordance claim (`emits_parent=false`).
- Missing support, unsupported media, and out-of-domain scores produce an
  abstained result with an explicit finding and human-review requirement; they
  are never converted to a negative biological conclusion.
- This module does not infer identity or consent and does not emit kinase state,
  generic all-omics fusion, treatment recommendations, or external-content
  traversals.

## Runtime and replay

`M1007CalibrationEngine` performs strict request validation, seven-control
preflight, deterministic scoped scoring, typed calibration diagnostics, canonical
JSON serialization, request/result digest binding, and replay verification.
`M1007Plugin` is parse-once and sealed with a weak token registry. `M1007Service`
is the API/CLI seam. FastAPI and Typer adapters use the same service and return
sanitized errors; the CLI refuses overwrite and exits nonzero for safe
abstention.

## Evidence and gates

The focused release matrix is in `evals/m10_07` and
`tests/fixtures/m10_07/scenarios.json`. It covers supported calibration,
support-threshold abstention, OOD abstention, unsupported media, replay/tamper,
determinism, API/CLI parity, duplicate JSON, token forgery, authorization, and
contract closure. The provisional benchmark runs 10 calls and uses 2e9 ns mean
and 3e9 ns p95 budgets.

Traceability is maintained in `docs/traceability/GLIO-PROTEOGEN-M10-07.csv`;
release metadata and the executable publication verifier are under
`release-evidence/m10_07`.
