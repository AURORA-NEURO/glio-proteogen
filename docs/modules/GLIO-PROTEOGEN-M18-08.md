# GLIO-PROTEOGEN-M18-08

M18-08 is a provisional, evidence-bounded translation-health monitor beneath the spatial
proteomics biomarker-panel projection. It turns caller-declared telemetry, support drift,
workflow effects and discrepancies into explicit health and rollback states; it never converts
unsupported evidence into a negative biological conclusion.

The implementation is deterministic and replay-verifiable. Seven upstream controls are checked
before observation traversal, all seven uncertainty dimensions are present, provenance binds the
request and control evidence, and unsupported or non-evaluable inputs produce a safe abstention.
The sealed plugin requires a parse-once validation token; API and CLI surfaces return sanitized
validation/authentication errors and share the same JSON schemas.

The ABI remains provisional because the dossier supplies behavioral requirements rather than a
frozen endpoint catalogue. No kinase activity, generic all-omics fusion, treatment recommendation,
identity inference, consent inference, or parent emission is implemented.
