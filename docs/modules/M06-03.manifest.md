## Data and model manifest

All executable fixtures are synthetic and non-clinical. The evaluator constructs a genuine
M06-01 formal-state result, then passes that complete immutable result through M06-03. The runtime
does not open raw files, resolve identifiers, follow URLs, call model services, fit parameters,
emit calibrated probabilities, or make protein/clinical/treatment claims. Scalar values are
copied transparently; interval values retain ordered bounds and center; categorical values retain
their category. Missing, unsupported, and non-valid upstream states return typed abstention.

The configuration declares locked preprocessing and tuning records but does not execute a learned
model. Every uncertainty dimension is not estimable. Evidence and provenance are caller-declared
receipts and do not authenticate issuer authority or scientific truth.

## Review and rollback

This module cannot self-approve. A future governed release must bind the external dossier review,
source commit, all seven schema digests, evaluator output, interface tests, benchmark report, and
reviewer decision. Corrections are append-only: submit a new request and new output path with the
prior digest as supersession context; never overwrite, mutate, relabel, or promote an old result.
