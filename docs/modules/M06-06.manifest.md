# GLIO-PROTEOGEN-M06-06 — uncertainty decomposition

Status: provisional local-only implementation. The permitted dossier behavioral
brief names seven uncertainty dimensions, sensitivity exposure, and safe
abstention. It does not freeze this operation name, estimator ABI, calibration
artifact, schema inventory, endpoint, or media type. Every public symbol in
this tranche is marked `0.1.0-provisional` and requires owner confirmation.

## Boundary

`decompose_protein_abundance_uncertainty` accepts the complete M06-05
`IntegrateProteinAbundanceConstraintsResult`, verifies both upstream canonical
digests, and emits either an evidence-derived seven-component decomposition or
an abstained result. The decomposition estimates measurement uncertainty from
posterior interval width, sampling from feature count, parameter sensitivity
from soft-constraint ablations, model-form exposure from constraint-family
diversity, identification from unevaluable evaluations, support from evidence
coverage, and transport from glioma feature coverage. Values are bounded
analytical estimates for research use and are not clinical probabilities.

Abstention remains fail-closed for an abstained/unsupported M06-05 result or a
policy method explicitly marked `unsupported`, `not_evaluable`, `missing`,
`uncalibrated`, or `unlocked`.

The contract includes the seven dimensions `measurement`, `sampling`,
`parameter`, `model_form`, `identification`, `support`, and `transport`.
Missing information is never converted into a negative estimate, and no
parent biomarker-panel, kinase, treatment, raw-spectra, or sequence output is
emitted.

## Limits and controls

- Canonical request: 4 MiB; canonical result: 8 MiB.
- Maximum components: 7; evidence and findings: 32 each.
- Nominal coverage: 0.90; the provisional evaluated gate would be 0.85–0.95.
- Seven upstream controls must be accepted/resolved/granted before nested
  upstream traversal.
- API and CLI use strict JSON, exact media type, bounded input, and parse-once
  validation. The plugin requires an issued, digest-bound validation token.
