## Allowed boundary

The runtime accepts strict, caller-declared typed context attributes and applicable mechanism
references. It emits a typed context profile only when every declaration is observed and safe;
otherwise it emits an explicit abstention with findings, support status, uncertainty, provenance,
evidence, and limitations. Parent emission is explicitly false and human review remains required.

No source bytes are traversed. M15-02 does not infer identity, lineage, subtype, disease biology,
consent, kinase activity, generic all-omics state, or treatment recommendation. Prohibited proxies,
inferred values, missing values, and unresolved declarations are not converted to negatives.
