The implementation binds request and execution-context identities and performs a seven-control
authorization preflight before reading upstream
metadata. It evaluates only caller-declared access markers (`deny` and `threat`), preserves
all eight security controls, and binds request/result digests for deterministic replay. The
explicit consent artifact must exactly match the granted context evidence; access and audit
records expose that bound evidence, and provenance records the upstream and consent input
digests. Evaluated access and audit records also retain the exact request principal, resource,
action, policy, timestamp, and decision state, preventing a self-rehashed result from relabeling
the authorization subject. Missing, mismatched, or unsupported consent/upstream references
abstain without a security decision. It never infers
proteins, proteoforms, isoforms, glioma biology, kinase activity, treatment, identity, or consent.
