# M02-01: protocol and metadata specification

M02-01 validates a pinned, versioned metadata profile for synthetic peptide-identification
records. It owns controlled terms, mandatory fields, units, cardinality, assay/specimen version
compatibility, conditional applicability, and unresolved-state semantics. It emits only a
versioned protocol-schema result and conformance profile supporting the parent protein-subtype
workflow. It does not identify peptides, judge assay validity, infer biology, calibrate a model,
own kinase activity, fuse omics, recommend treatment, or establish clinical readiness.

## Validation boundary

1. Require consent, resolved identity/lineage, approved configuration, provenance, quality,
   support, and intended-use references before traversing metadata fields.
2. Bind each request to one exact protocol-profile identifier and version. No profile, term,
   field, unit, assay version, or specimen version is inferred from free text.
3. Validate mandatory keys, closed controlled-vocabulary terms, explicit units, and declared
   cardinality without silent coercion.
4. Apply pinned compatibility rules across assay, specimen, and conditionally applicable fields.
   A label-free reagent field may be explicitly not applicable; the same state is incompatible
   with an isobaric-label profile that requires a reagent term.
5. Preserve explicit unresolved values as unresolved. A mandatory unresolved value quarantines
   the record for governed review and is never converted to absent, negative, or conformant.
6. Return closed conformance findings, support/uncertainty, provenance, evidence, and limitations.
   Do not return raw spectra, sequences, peptide calls, protein-subtype interpretations, kinase
   state, fused interpretation, or treatment advice.

The first implementation is a deterministic schema-first validator over a pinned synthetic
profile. It is not an ontology registry, assay model, anomaly detector, PCA/ICA analysis, event
ledger, or scientific interpretation engine.

## Evidence gate

Gate G0 uses eight small synthetic, non-clinical cases:

- one canonical metadata object conforms and is stable under irrelevant input ordering;
- missing mandatory metadata, an unsupported controlled term, an incompatible unit, and scalar
  over-cardinality fail with explicit findings;
- label-free optional reagent `not_applicable` is accepted while isobaric required reagent
  `not_applicable` is rejected under the pinned conditional rule;
- an unresolved mandatory value quarantines and never becomes a negative finding;
- consent denial occurs before metadata traversal.

These checks establish deterministic behavior for one pinned synthetic peptide-identification
metadata profile. They do not establish ontology completeness, assay validity, biological
correctness, calibration, transportability, or clinical readiness. One broad batch-validator
microbenchmark is a representative latency regression tripwire, not scientific evidence or an
asymptotic-complexity claim.
