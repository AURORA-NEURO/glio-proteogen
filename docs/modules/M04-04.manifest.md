## Schema and interface manifest

The public registry exposes exactly 13 strict JSON Schema 2020-12 contracts. Metadata declares the
4 MiB request bound, rate scale 1,000,000, parent target, strict metadata-only operation, and false
raw payload, external traversal, model execution, identity, consent, protein, proteoform,
modification localization, CN regression, discordance, kinase, fusion, and treatment authority.

Python, engine, service, plugin, API, and CLI share exact strict reconstruction and result
semantics. HTTP POST is permitted because the operation is metadata-only. CLI rejects duplicate
keys, unknown fields, coercion, an oversized request before decode, existing output, symlink,
junction, and reparse output and publishes one atomic new file.

Role-fact input identifiers remain exact opaque upstream `input.*` identifiers. Evidence identity
and version reuse with conflicting content rejects. Receipt disposition is derived from canonical
finding codes, and the zero-digest assembly sentinel is never a publicly valid contract value.

## Reviewer sign-off

M04-04 cannot self-approve. A governed release record must name an externally authenticated
reviewer, role, decision, timestamp, exact module and contract version, schema digests, source
commit, fixture digest, 72-case eval digest, interface-test digest, benchmark digest, recursive
privacy and authority evidence, and reviewed result/policy/configuration digests. Critical
discrepancy, novel or OOD state, support override, claim promotion, release exception, optional
warning, quarantine, abstention, or unresolved biological conflict remains external review work.

## Rollback and recovery

1. Reject, quarantine, or abstain at the boundary without overwriting upstream or prior evidence.
2. Retain the exact request, upstream result, policy, profiles, fact ledger, facts, metrics,
   findings, evidence, and review record.
3. Restore configuration or aggregates through the externally governed source; never repair,
   clip, relabel, deduplicate, or reinterpret them inside M04-04.
4. Submit a corrected request naming the superseded immutable result digest and publish only to a
   new nonexistent output path.
5. Replay all 72 cases, 13 schemas, interfaces, benchmark, privacy/authority checks, traceability,
   and review against the corrected immutable version.

Supersession is append-only and never deletes, mutates, re-signs, overwrites, or silently promotes
a prior result, fact ledger, or source artifact.
