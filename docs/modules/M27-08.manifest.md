| --- | --- |

| Input boundary | Caller-declared M27-07 artifact references (`application/vnd.glio-proteogen.m27-07+json` exactly) plus seven execution controls |

All values remain metadata-only. The module does not infer proteins, proteoforms, isoforms,
glioma biology, kinase activity, treatment, identity, consent, or generic all-omics fusion.
Retirement is executed only when every criterion, migration, preservation, communication, and
archive control is satisfied; otherwise a review-required abstention is emitted.

An executed result is also bound to an executed retirement package; contradictory package states
are rejected during strict result validation before replay or publication.

The upstream media type is an exact compatibility boundary.  Values that merely contain
`m27-07`, add parameters, or use a different vendor/type are rejected before evaluation; the
service does not infer compatibility from caller-controlled text.
