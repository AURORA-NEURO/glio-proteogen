M16-03 performs component-specific integration beneath the KINOPHOS object
consumer. The runtime replays caller-declared source contributions, reliability,
disagreements, and signed propagation into an attributable integrated object;
it does not read opaque artifact bytes, perform generic all-omics fusion, verify
unavailable signatures, emit kinase activity, recommend treatment, infer
identity/consent, relabel upstream evidence, erase disagreement, or convert
unsupported/missing evidence into a negative finding.

Reliability below the configured threshold and `not_evaluable` contributions
abstain with explicit findings and `human_review_required=true`. Supported
integration preserves open disagreements and signed propagation as caller-
declared records. The result is contextual (`emits_parent=false`) and is not a
kinase-state or clinical conclusion.

Executable requirement links are in
`docs/traceability/GLIO-PROTEOGEN-M16-03.csv`. The synthetic, non-clinical
scenario corpus is `tests/fixtures/m16_03/scenarios.json`.
