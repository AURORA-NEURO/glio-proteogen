The additive research lane uses model family
`glioma-discordance-selective-calibration/1.0.0`: paired protein/RNA effects
with propagated standard errors are fit by quality-weighted damped robust
logistic IRLS, then calibrated with the existing conformal rank and subgroup
coverage checks. It requires at least eight supported labeled observations and
both discordance classes; missing/unsupported values never become negative
evidence. The opaque digest score remains compatibility-only.

No endpoint, media type, calibration catalogue, or metric is declared frozen by
this manifest. The module remains provisional until the owning authority freezes
those surfaces.
