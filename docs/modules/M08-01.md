## Implemented boundary

- Strict immutable Pydantic contracts for feature definitions, scalar/interval/
  categorical/vector values, missingness, invariants, invariant results,
  migration rules, schema envelopes, and typed result metadata.
- Deterministic canonical request and result digests with replay verification.
- A finite invariant language: `all_values_observed`, numeric comparisons, and
  quoted categorical equality. Unknown expressions become `not_evaluable`; no
  arbitrary expression execution is possible.
- Explicit hard-error versus warning invariant severity. Error violations are
  invalid; warning violations remain valid but are retained in the result.
- Fail-closed approved-configuration, identity/lineage, provenance, consent,
  quality, support, and intended-use preflight controls.
- Explicit seven-dimension non-estimable uncertainty profile, provenance control
  ledger, evidence references, limitations, and no parent/proteotype emission.
- Sealed parse-once plugin plus FastAPI and Typer interfaces with canonical
  typed/JSON parity and strict duplicate-key rejection.

The module does not own kinase state, generic all-omics fusion, treatment
recommendation, identity inference, evidence mutation, or conversion of missing
or unsupported evidence into a negative biological finding.
