M15-05 accepts caller-declared, strictly ordered time-course, primary-recurrence,
treatment-era, clone, territory, or state-transition observations. The current
implementation performs bounded deterministic metadata replay: it preserves the
declared order and references as trajectory states and emits explicit
`not_evaluable` change-point records. It does not read opaque artifact bytes,
fit a Bayesian/state-space/mechanistic/foundation-assisted model, infer a
biological state or identity, perform all-omics fusion, emit KINOPHOS kinase
activity, recommend treatment, or convert unsupported evidence to a negative.

The seven caller controls (approved configuration, identity lineage, provenance,
consent, quality, support, intended use) are checked before observation
traversal. The output is explicitly `emits_parent=false`; the parent target is
context only. All modeled output carries uncertainty statements that the
metadata replay is not a biological state estimate, and owner review is required
before any change-point or evolutionary claim is promoted.

Executable evidence is recorded in `docs/traceability/GLIO-PROTEOGEN-M15-05.csv`.
The synthetic corpus is `tests/fixtures/m15_05/scenarios.json`; it is non-clinical
and contains no patient, identity, treatment, or raw assay data.
