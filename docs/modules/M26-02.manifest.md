## Responsibility and boundary

M26-02 owns immutable, queryable lineage across source data, transformations,
features, models, references, policy, and evidence. It emits only a lineage
graph and reproducibility bundle. The implementation never infers protein
subtype, proteotype, kinase activity, identity, consent, generic all-omics
fusion, or treatment recommendation, and it never relabels or erases upstream
disagreement.

The M26-01 dependency is caller-declared media only:
`application/vnd.glio-proteogen.m26-01+json`. M26-01 has no published runtime
ABI in this lane, so M26-02 deliberately has no M26-01 service import. The
request requires the upstream artifact to be present in `source_artifacts`;
issuer authority and registry semantics remain upstream.

## Implemented controls

- immutable node and edge IDs, exact artifact/node versions, closed node-kind set;
- broken-link, duplicate-ID, root, cycle, graph-digest, and replay-bundle checks;
- canonical request/result IDs and SHA-256 replay verification;
- fail-closed seven-control preflight with explicit review abstention;
- seven uncertainty dimensions, provenance, evidence, limitations, and human-review flag;
- strict JSON duplicate-key/non-finite/size controls with API/CLI/plugin parity;
- no-overwrite CLI behavior and non-zero exit for abstained construction.

The module remains research-and-development only pending the dossier's analytical,
external, subgroup, transport, human-factors, and prospective validation gates.
