## Responsibility and boundary

M26-06 evaluates only caller-declared controls for proteomics access and
privacy posture. It records least privilege, encryption, secrets handling,
isolation, consent, de-identification, audit, and threat-detection statuses,
with typed rationale, evidence, findings, audit records, provenance, and
review posture. It does not inspect raw biological payloads or turn a missing
control into negative biological evidence.

The deterministic service performs a fail-closed seven-control preflight
(configuration, identity, provenance, consent, quality, support, and intended
use), then evaluates the eight requested controls. FastAPI, Typer, SDK, and
the strict JSON plugin use this same service boundary. Canonical request and
result bytes support replay and tamper detection.

## Safety and non-authority guarantees

- caller declarations are not identity, consent, treatment, or biological
  truth; no such property is inferred from a payload or control label;
- an explicit consent artifact must exactly match the granted context evidence;
  missing or substituted consent references abstain before an access decision;
- failed, not-evaluable, review-required, or unsupported controls abstain
  safely and retain the unresolved posture for human review;
- malformed/duplicate JSON, wrong media, forged plugin tokens, digest changes,
  revoked consent, and unsafe output overwrites fail closed;
- all seven uncertainty dimensions are explicit `not_estimable` values because
  this module does not estimate biological or population uncertainty;
- no generic all-omics fusion, kinase activity, treatment recommendation,
  identity inference, or consent inference is emitted.
