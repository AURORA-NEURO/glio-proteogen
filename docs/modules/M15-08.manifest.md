M15-08 owns the structured chain from caller-declared input through mechanism
assertion, counter-evidence, validation route, uncertainty, and claim ceiling.
The current implementation is deterministic metadata replay only: it does not
read opaque artifact bytes, infer a biological mechanism, mutate or relabel
upstream evidence, erase disagreement, infer identity/consent, perform generic
all-omics fusion, emit KINOPHOS kinase activity, recommend treatment, or convert
unsupported/missing evidence into a negative finding.

Every emitted dossier keeps weak links and planned validation visible. The
runtime requires seven caller controls before input traversal, emits explicit
uncertainty and a `PROVISIONAL_ABI_PENDING_REVIEW` finding, sets
`human_review_required=true`, and never emits the parent (`emits_parent=false`).
The dossier is review-ready as a reconstructable evidence package, not a
clinical, biological, or treatment conclusion.

Executable requirement links are in
`docs/traceability/GLIO-PROTEOGEN-M15-08.csv`. The synthetic, non-clinical
scenario corpus is `tests/fixtures/m15_08/scenarios.json`.
