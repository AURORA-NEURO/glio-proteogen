## Data and model manifest

All fixture data is synthetic and non-clinical. `tests/fixtures/m13_06/scenarios.json` is the
locked eight-case corpus: five supported perturbation kinds, unsupported input, out-of-envelope
response, and denied-control authorization. The fixture records the dossier slice, requirement
SHA, response envelope, and claims ceiling. The engine never opens a referenced artifact and never
turns unsupported or missing support into a negative response.

The dossier lists possible architecture directions but leaves the runtime ABI open. This release
selects only the frozen safety behavior: strict typed envelopes, bounded caller-declared replay,
negative-control checks, provenance, uncertainty, and explicit abstention. The architecture/model
directions remain declared-but-not-executed until the owning authority freezes the ABI.

## Authority, review, and rollback

M13-06 cannot self-approve biological validity, calibration, mechanism, or treatment claims. A
governed release record must bind the module version, requirement SHA, fixture digest, schema
digests, source commit, evaluator result, interface tests, benchmark, and an externally
authenticated Computational biology reviewer. Corrections are append-only: submit a new request,
optionally naming `supersedes_result_digest`, and publish a new result without overwriting prior
evidence.
