## Scope and safety

The runtime only processes caller-declared typed artifacts and constraint metadata. It does not
open external files, traverse ontologies or graphs, call a model service, infer identity or
consent, or convert missing/unsupported input into a negative result. Hard violations, missing
feature bindings, duplicate feature artifact identifiers, and authorization failures are safe
abstentions or denials. Soft violations remain visible and require a same-constraint ablation
record, making prior dominance auditable.

Every output carries typed support, uncertainty, provenance, evidence, limitations, the exact
request digest, and a result payload digest. Canonical replay rejects non-canonical bytes,
oversized bytes, invalid result shapes, or digest mismatch.
