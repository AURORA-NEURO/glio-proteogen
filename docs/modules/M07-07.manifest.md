## Installed deterministic boundary

The implementation is a schema-first, stateless, quarantine-first gate. It
does not manufacture predictions. The public caller must declare candidates;
selection occurs only after seven control references, the full M07-06 result,
the sensitivity envelope, all four calibration dimensions, and the locked
support/OOD/error thresholds pass. Rejected candidates become bounded
diagnostics. Missing, unsupported, OOD, non-evaluable, and under-calibrated
inputs produce an explicit abstention with no scientific value or prediction
set.

The result envelope contains request/result digests, selected estimates and
prediction sets when supported, diagnostics, support decision, typed
uncertainty, seven-control provenance, evidence, limitations, and explicit
review state. Canonical request/result digests are recomputed during
validation; candidate, strata, and artifact sequences are semantically sorted
for replay. The plugin token binds object identity and request digest and is
not a substitute for authentication.

## Reviewer and recovery boundary

M07-07 cannot self-approve. External review is required for critical
discrepancy, novel or OOD state, support override, claim promotion, release
exception, unresolved biological conflict, or promotion of the provisional ABI.
Any correction names the superseded result digest and publishes a new result,
request, evidence set, and review record. The prior artifact remains immutable
and auditable.
