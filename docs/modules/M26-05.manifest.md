## Responsibility and boundary

M26-05 records caller-declared input quality, model behavior, uncertainty,
abstention, drift, latency, error, resource, reviewer-action, retention,
dashboard, and alert-state signals. It binds every sample to retained
evidence, a typed unit, an observation time, and the upstream M26-04 artifact.
The runtime emits a complete telemetry stream only when every requested metric
is present; missing signals produce an explicit safe abstention.

The service is deterministic and stateless. It performs a seven-control
preflight (configuration, identity/lineage, provenance, consent, quality,
support, and intended use), then builds canonical request/result digests,
provenance, evidence, alert, finding, uncertainty, and replay records. FastAPI,
Typer, and the strict JSON plugin share this service boundary.

## Safety and non-authority guarantees

- caller-declared operational signals are retained and are never converted from
  missing, unsupported, or not-evaluable to negative biological evidence;
- drift and error thresholds create review-required alerts; they do not infer a
  subtype, treatment, identity, consent, or kinase state;
- failed controls, malformed/duplicate JSON, wrong units/media, forged plugin
  tokens, tampered result digests, and unsafe output overwrites fail closed;
- all seven uncertainty dimensions are explicit `not_estimable` values because
  this module does not estimate biological uncertainty;
- no generic all-omics fusion, kinase activity, treatment recommendation,
  identity inference, or consent inference is emitted.
