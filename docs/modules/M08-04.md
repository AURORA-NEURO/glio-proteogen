# GLIO-PROTEOGEN-M08-04 — probabilistic or advanced estimator

M08-04 owns the primary probabilistic or mechanism-guided estimator beneath transcript-protein
discordance. The current implementation is a deterministic, caller-declared posterior proxy that
locks the safety envelope and replay ABI while the dossier leaves the model catalogue,
isoform-aware quantification representation, and public symbols provisional.

Authority is limited to dossier SHA-256
`0a6b200cbe073db13a4bcf315edc23ab97edfe6f500bc7ea2785f5e1c70da181`, exact lines `2688–2731`.
Owner/safety/gate are Bioinformatics / S2 / G2. The contract version is `0.1.0-provisional`.

## Locked responsibility and boundaries

- Inputs are content-addressed M08-03 baseline evidence, caller-declared mass-spectrometry,
  genome/transcriptome, PTM, and isoform-aware feature observations, approved configuration,
  identity/lineage, provenance, consent, quality, support, and intended-use controls.
- Outputs are typed posterior estimates, optimization diagnostics, seven-dimensional uncertainty,
  support status, provenance, evidence, limitations, and an explicit parent target of
  `protein_subtype`. `emits_parent` is permanently false in this provisional slice.
- KINOPHOS kinase-state ownership, generic all-omics fusion, treatment recommendations, identity or
  consent inference, upstream mutation, disagreement erasure, and missing-to-negative conversion
  are outside this module.
- Raw spectra, sequences, accessions, and untrusted external content are never traversed. Feature
  values are caller-declared, finite, unit-labelled, weighted, and optionally isoform-bound.

## Contract and runtime

The contract closes configuration priors, hard/soft constraints, optimizer, seed, iteration cap,
feature state/value agreement, unique identities, M08-03 media-type binding, canonical request and
result digests, posterior scalar/interval/categorical shapes, diagnostic status/value agreement,
explicit review on abstention, and safe support states.

The runtime performs seven-control authorization before typed traversal. It supports three
provisional deterministic architecture paths: learned, mechanism-guided, and proteoform
probabilistic. Every supported path uses bounded signals, declared priors, hard-constraint count,
and seed as explicit inputs. Missing, unsupported, OOD, unresolved, or quality-failed sources
abstain without estimates. The service verifies and replays exact result envelopes; tamper and
request-digest changes fail closed.

## Interfaces and evidence

The isolated `glio_proteogen.adapters.m08_04` surface exposes FastAPI schema/estimate routes and
Typer export-schema/validate/estimate commands. All use one strict, bounded JSON parse path.

The release evidence includes 20 focused tests, evaluator scenarios for all three architecture
families plus missing/OOD/consent safety, replay/tamper verification, a ten-call benchmark, branch
coverage, traceability, and wheel/sdist import checks. This evidence demonstrates contract and
safety behavior; it does not claim trained-model accuracy, calibrated clinical probability,
transportability, or owner-approved release status.
