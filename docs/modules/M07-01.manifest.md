## Data and model manifest

The fixture corpus is synthetic, non-clinical and contains only opaque content-addressed
references, typed values and caller-declared controls. The runtime never traverses an artifact
reference or external file. It does not run a scientific, probabilistic, Bayesian, PCA/ICA or
learned model. The dossier lists those architecture options; this provisional implementation
selects the narrow schema-first deterministic boundary until an owner-approved estimator and
feature catalogue are frozen.

All seven uncertainty dimensions are explicit `not_estimable` values. Missing, not-applicable,
unknown and unsupported states remain typed states. A result abstains with review-required
support when an invariant cannot be evaluated without imputation. An error- or warning-severity
violation is invalid and limited; no invalid result is presented as a supported result.

## Replay and control manifest

Every request is canonicalized and bound by a SHA-256 request digest. The result binds the exact
request, every declared invariant, provenance controls, evidence references, limitations and its
own result digest. Canonical bytes are re-derived for replay. Tampered result content, digest or
canonical bytes are rejected. Consent, resolved identity/lineage and five accepted upstream
controls are checked before feature traversal.

## Reviewer and rollback plan

This manifest is evidence of implementation behavior only. It does not authenticate an issuer,
reviewer, consent authority, feature unit, biological measurement, model, or clinical conclusion.
Promotion requires an externally governed reviewer and a new owner-approved ABI. Corrections are
append-only supersessions bound to a new request/result digest; no prior evidence is overwritten.
