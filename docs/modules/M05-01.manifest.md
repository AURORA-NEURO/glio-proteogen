## Reviewer sign-off

Critical discrepancy, novel/OOD state, support override, claim promotion, release exception, and
unresolved biological conflict require an external governed reviewer. Release evidence must record
reviewer identity, role, decision, time, the exact source revision, schema IDs, fixture digest, eval
report digest, benchmark report digest, wheel digest, and this manifest digest. M05-01 cannot
self-approve, authenticate a reviewer, promote a claim, or confer release authority.

## Rollback and recovery

1. Reject unauthorized or malformed ingress before governed declaration traversal.
2. Abstain for unsupported/OOD declarations; quarantine supported invariant failures.
3. Retain the immutable request, result, evidence index, receipt, and verifier output.
4. Disable the candidate deployment externally and restore the last approved artifact.
5. Correct the protocol/profile under their owning authorities; never rewrite the prior result.
6. Issue a new request with `supersedes_result_digest` bound to the prior result.
7. Replay all 40 cases, the exact maximum benchmark, static/coverage/package gates, and interfaces.
8. Obtain new external sign-off bound to replacement digests before promotion.
