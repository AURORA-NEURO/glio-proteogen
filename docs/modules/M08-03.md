## Implementation

- Strict immutable contracts for locked preprocessing/tuning/uncertainty/
  benchmark configuration, representation handoff, feature observations,
  estimate, diagnostics, findings, uncertainty, support, provenance, evidence,
  and limitations.
- Transparent deterministic baseline over caller-declared observed features:
  arithmetic mean for the statistical option, index-weighted mean for the
  pathway-network option, and median for the selective complex-graph fallback.
  The bounded score is a diagnostic, not a calibrated clinical probability;
  the calibration artifact is carried as an explicit reference.
- Explicit abstention for missing/unsupported features, suspicious OOD source
  declarations, unresolved upstream controls, and unsupported handoff media.
- Seven-control preflight, canonical request/result digests, deterministic
  replay, tamper verification, and a sealed parse-once plugin.
- FastAPI schema/estimate endpoint and Typer
  `protein-subtype-baseline export-schema|estimate` interface with strict JSON,
  duplicate-key rejection, no-overwrite output, and typed/JSON parity.

The module emits only a baseline estimate with diagnostics and uncertainty. It
does not own kinase state, generic all-omics fusion, treatment recommendation,
identity or consent inference, evidence mutation, or parent subtype emission.
