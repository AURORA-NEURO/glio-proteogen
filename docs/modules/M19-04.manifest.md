## Data and model manifest

All fixtures and benchmark inputs are synthetic, non-clinical, opaque metadata. M19-04 performs
no network access, external-content traversal, identity lookup, consent inference, registry or
database lookup, model fitting, calibration, probabilistic prediction, all-omics fusion, kinase
analysis, or treatment recommendation. The installed model count is zero. Caller-declared source
and evidence digests make replay tamper-evident but do not authenticate measurement, issuer,
reviewer, identity, consent, or scientific truth.

## Release and review

The release candidate must retain the exact source commit, dossier digest/slice, schema digests,
fixture digest, evaluator report, benchmark report, focused test command, coverage command, wheel
and sdist hashes, isolated import result, and external reviewer decision. Local evidence is a
consistency gate only; it is not clinical qualification, scientific validation, authentication,
or promotion authority. Any correction is a new immutable result and new review record.
